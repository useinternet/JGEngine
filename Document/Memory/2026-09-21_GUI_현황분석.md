### 한 줄 요약
GUI 모듈은 빌드·실행이 정상이고 래퍼 경계(`HGUI`, `JGWidget`)도 지켜지고 있지만, **위젯 업데이트 경로가 통째로 죽어 있고**(플래그 설정 API 부재 + `UpdateFrameWidgets`가 `Update()` 호출) 메뉴 트리에 이름 충돌·CanAction 미사용 버그가 있다. 종료 경로는 스케줄 태스크 미해제·위젯 맵 미정리·GPU 완료 대기 없는 SRV 힙 해제가 겹쳐 있으나 지금은 종료 경로가 하나뿐이라 증상이 없다.
