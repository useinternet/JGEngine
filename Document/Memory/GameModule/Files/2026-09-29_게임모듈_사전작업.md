## 사용 순서 (가이드 요약)
1. 엔진 루트 `GenerateProjectFiles.bat`(= `Build/BatchFiles/PreBuild.bat`) 1회 — 엔진 `Temp/CodeGen` 이 있어야 한다.
2. `Build/BatchFiles/CreateGameProject.bat <Dir> [Name]` — 이름은 ASCII 식별자, `JG` 시작 · 엔진 모듈 폴더명 금지.
3. `<Dir>/GenerateProjectFiles.bat` → `<Dir>/<Name>.sln`, `<Dir>/Temp/{ProjectFiles,CodeGen}`, 3rd party 를 `<Dir>/Bin/<Cfg>` 로.
4. `<Name>.sln` DevelopEngine|x64 빌드 → `<Dir>/Bin/DevelopEngine/JGLauncher.exe` → 창 `JGEditor - <Name>`.

## 코드 지도
| 무엇 | 어디 |
|---|---|
| 루트 결정 | `CoreSystem.cpp` `resolveRootDirectories` — 툴은 `HCoreSystemArguments::ProjectDirectory`(`-project=`), 런타임은 `../../*.jgproject` 가 있으면 프로젝트 모드. 결과는 `HCoreSystemGlobalValues` 의 `EngineDirectory` · `ProjectDirectory` · `ProjectName` · `bProjectMode` |
| 루트 읽기 | `HFileHelper::EngineDirectory()` · `ProjectDirectory()` · `Project{Source,Bin,Temp,CodeGen}Directory()` · `IsProjectMode()` — Core 가 StaticLib 라 DLL 마다 static 이 따로여서 매번 GlobalValues 에서 읽는다 |
| `.jgproject` | `Core/FileIO/ProjectDescriptor.*` (`Name` · `EngineRoot` · `GameModules` · `EditorModules`). 엔진 루트 = EngineRoot → `JGENGINE_ROOT` |
| BuildTool | `-project=` 프로젝트 모드(모듈 스캔 = 프로젝트 `Source`, 엔진 모듈 경로는 엔진 절대경로 접두, `<Name>.lua` · `<Name>.sln`, 3rd party 복사), `-newproject= [-name=]` = `Class/ProjectCreator.*` 가 `Build/Templates/GameProject` 를 토큰 치환(`{PROJECT_NAME}` · `{PROJECT_NAME_UPPER}` · `{ENGINE_ROOT}` · `{ENGINE_ROOT_WIN}`)해 복사 |
| HeaderTool | `-project=` 면 게임 모듈만 → 프로젝트 `Temp/CodeGen`. 엔진 모드는 `*.module.json` 에서 대상 수집. 두 모드 모두 바뀐 파일만 쓴다 |
| 에디터 호스트 | 런처 `LaunchModule = "JGEditor"`. `JGEditor.cpp` 가 엔진 모듈 6개 연결 · `Dev/DevAI` 메뉴 · DevFeature 씬 뷰, 프로젝트면 `.jgproject` 의 GameModules → EditorModules 연결, 종료 시 역순으로 먼저 내림 |

- Core 헤더(`FileHelper.h` · `CoreSystem.h`)가 바뀌어 모든 모듈이 한 번 전부 재컴파일된다.

- 새 툴은 PreBuild 2회차에 컴파일 대상 0(옛 툴은 매번 .cpp 106개 mtime 갱신). 종료 코드도 139 → 0.
- worktree 를 `%TEMP%`(스크래치패드) 아래 두면 MSBuild 가 헤더 의존을 추적하지 않는다(MSB8029). 헤더를 바꿨으면 `-t:Rebuild`.
- `git show HEAD:<file>` 은 LF, 작업 트리는 CRLF(core.autocrlf=true) → `git merge-file` 의 base 로 쓰면 전부 충돌. `git cat-file --filters HEAD:<file>` 을 쓴다.
