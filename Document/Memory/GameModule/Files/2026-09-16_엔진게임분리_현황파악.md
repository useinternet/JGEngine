## 확정 사실
- **단일 블로커의 정체**: `HFileHelper::EngineDirectory()` 가 `"../../"` 리터럴(`FileHelper.cpp:298`). Bin/Temp/CodeGen/Content/Source/ThirdParty/Shader 9개 파생 함수가 전부 여기 매달려 있고, "엔진 루트 = 프로젝트 루트 = CWD 두 단계 위"가 전 시스템의 암묵 전제.
- **이미 절반 준비돼 있음**: BuildTool·HeaderTool 양쪽에 `EngineWorkDirectory`/`UserWorkDirectory` 2분할 존재. BuildTool 은 `_userModuleInfoMap` 을 별도 premake 그룹으로 뽑는 코드까지 완성(`BuildTool.cpp:207` `getUserProjectName()`). `UserWorkCategories` 가 빈 배열이라 결과가 공집합일 뿐.
- **Configuration 4종은 수정 불필요**: `DevelopEngine/DevelopGame/ConfirmGame/ReleaseGame` 이 이미 "엔진 Release + 게임 Debug" 조합을 전제로 설계돼 있고 각 `module.json` 도 그에 맞게 채워져 있다.
- **런타임 영향 범위가 작다**: 엔진 경로 호출부가 런타임에 5곳뿐(Asset 3, Graphics 1, Module 1). 작업의 90%가 `Source/Programs` 두 툴 + premake 템플릿.
- 생성물 목록(직접 수정 금지): 루트 `jgengine.lua`, 루트 `JGEngine.sln`(내부는 `Temp\ProjectFiles\*.vcxproj` 참조), `Temp/CodeGen/**`, `ModuleInfoTemplate.json`.
- `Source/Runtime/Game`, `Source/Runtime/GameFrameWorks` 는 `int dummy()` 뿐인 빈 스텁인데 `Game` 은 SharedLib 라 `Game.dll` 이 빌드되고 코드젠 대상에도 들어가 있다 → 유저 게임 모듈과 **이름 충돌 위험**.

## 새로 발견한 버그 (기존 Programs 메모에 없던 것)
- **`_userModuleSet` 이 어디에서도 대입되지 않는다** (`HeaderTool.h:99`, 사용처 `HeaderTool.cpp:105`). `allowedModules.contains()` 가 항상 false → 유저 모듈은 리플렉션 코드젠이 통째로 생성되지 않는다. 분리 작업의 정면 블로커.
- **`HeaderTool.cpp:160-170` `LocalRelativePath` 가 `EngineSourceDirectory()` 기준**으로만 상대화된다. 이 값이 그대로 생성 코드의 `#include`(`:994`)가 되므로, 엔진 `Source/` 밖의 게임 헤더는 절대 경로가 include 문에 박힌다.
- **`ModuleInfo.h:119-120` 이 `CodeGenPath.Remove(0, EngineDirectory().Length())`** 로 문자열 길이만큼 앞을 잘라낸다. `EngineDirectory()` 를 절대 경로로 바꾸는 순간 깨진다 — 루트 2개화와 반드시 동시에 고쳐야 하는 자리.

## 주의
- **Graphics 가 아직 컴파일되지 않는다**(`Document/Graphics_TODO.md` 1-2 ~ 1-6 미완). 빌드 시스템을 건드리는 동안 "내가 깼나 원래 깨졌나" 구분이 안 된다. Graphics 1-2 ~ 1-5 를 먼저 끝내 초록 기준선을 만들 것을 권장했다.
- **Phase 1 의 회귀 테스트가 전 과정의 안전망**: `-project=` 를 엔진 루트로 주면 기존과 동일한 `jgengine.lua`/`JGEngine.sln` 이 나와야 한다. 이건 빌드 성공 여부와 무관하게 검증 가능하니 먼저 세울 것.
- premake `files { path .. "**.cpp" }` 는 **생성 시점에 글롭을 전개해 파일 목록을 박는다.** 코드젠 파일이 디스크에 없으면 조용히 빠진다. 새 게임 프로젝트 1회차 생성에서 반드시 밟는 함정.
