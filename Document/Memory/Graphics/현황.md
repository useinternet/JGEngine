## 1. 역할과 범위

Graphics 모듈은 GPU 리소스(텍스처 · 버퍼 · 머터리얼 · PSO)와 프레임 제출, 장면 데이터(`PScene`)와 그리기(`PSceneRenderer`), 메시/텍스처 에셋과 FBX 임포트를 맡는다. 게임 프레임워크는 `PScene`의 ID API로 장면 데이터만 고치고, 그리기는 Graphics가 한다. 게임 콘텐츠(보드 · 카드)는 이 위에 올라가는 것이고 이 문서의 범위가 아니다.

### 렌더 파이프라인 한 눈에
| 개념 | 구현 | 비고 |
|---|---|---|
| 머터리얼 도메인 | `EMaterialDomain::Surface`(메시 표면 → G버퍼 MRT 4장) · `Screen`(풀스크린 6정점 `SV_VertexID`, 합성 같은 화면 공간 패스) | 2026-09-29 `Scene` → `Screen` 개명(`HScreenDrawArguments`, `MATERIAL_DOMAIN_SCREEN`) |
| 머터리얼 → 셰이더 | `HRawMaterialConstructArguments`(도메인 · 프로퍼티 정의) → `PDX12Material::Initialize`(`buildPropertyLayout`: CB 256B 정렬, 텍스처 슬롯에 기본 텍스처) → `Compile(ShaderCode)`(템플릿 `__PS_*_CONTENTS_SCRIPT__` 치환, 텍스처 토큰은 식별자 경계 치환) → `PDX12GraphicsShader::Compile`(FXC `D3DCompile2`, `D3DCOMPILE_PACK_MATRIX_ROW_MAJOR`) | 바이트코드는 셰이더 객체(`EShaderDomain`별) 소유. 샘플러 이름은 컴파일 시 박힘 |
| 프레임 | `BeginFrame`(큐 `Begin`: 2프레임 전 펜스만 대기 · 미룬 해제 · 리드백 콜백) → 드로우(Default 리스트) → `EndFrame`(업로드 기록 → 프레임버퍼 갱신 → 리드백 기록 → 우선순위 순 제출 · Signal → Present) | `PCommandQueue::FramesInFlight = 2`, 프레임 인덱스별 `HFrameContext`(할당자 · 업로드 페이지 · 디스크립터 힙) |
| 커맨드 리스트 우선순위 | `ECommandListPriority`: `Upload`(0) < `Default`(1000) < `Readback` < `Present` | 같은 버킷 안 순서는 정해져 있지 않다 |
| CPU↔GPU 전송 | `PResourceStagingManager`: `RequestBufferUpload` · `RequestTextureUpload` · `RequestTextureReadback`(비동기, 어느 스레드 · 시점) / `ReadbackTextureImmediate`(동기, 전용 리스트 `ExecuteImmediate`) | 2026-09-18 설계 규칙. COPY 큐 없음 |
| 리소스 상태 | `PResourceStateTracker`(전역 상태 맵 + 리스트별 보류 배리어) | API 파괴 뒤 호출은 `HDirectXAPI` null 가드 폴백 |
| PSO / 루트 서명 | `PGraphicsPipelineState::Finalize` → `computeGraphicsPSOHash`(필드 단위, 바이트코드 · 시맨틱은 내용 해시) → 전역 캐시 | 새 PSO마다 Trace `Graphics PSO created. cache size N`. 컴퓨트 PSO는 아직 원본 바이트 해시 |
| 리소스 해제 | 모든 해제가 `PDirectX12API::DestroyCommittedResource` → `PCommandQueue::DeferRelease`(프레임 번호 표시) → 그 프레임 완료 뒤 놓음 | 5-5. 로드 스레드에서도 불림 |
| 메시 | `JGStaticMesh`(에셋: `HStaticSubMesh::Vertices/Indices` CPU 사본, `JGPROPERTY HBBox _bounds`) → `GetMesh()` 지연 생성 → `PStaticMesh : IMesh`(`HRenderSubMesh` VB/IB, DEFAULT 힙 `GPULoad`) | 정점 POD `HVertexData` 56B. 에셋과 렌더 메시 분리(메모리 뿌리 규칙) |
| 장면 | `PScene`: `HSceneMesh`(`IMesh` 참조 · 서브메시별 머터리얼 · 월드 행렬) · `HSceneCamera`(뷰 행렬 · 위치 · FovY · Near/Far)를 `HSceneMeshID`/`HSceneCameraID`로 생성 · 조회 · 수정 · 삭제 | 데이터만 든다. 메인 스레드 전용. 리소스는 참조만 |
| 패스 | `PSceneRenderer::Render(scene, cameraID)`: 지오메트리 패스(G버퍼 Albedo R8G8B8A8 · Normal_Metallic R16G16B16A16F · Specular_Roughness R8G8B8A8 · Depth R32F + 깊이 D24S8) → 합성 패스(Screen 머터리얼, 텍스처 프로퍼티 `GAlbedo/GNormal/GDepth`, 고정 방향 램버트) → 출력 텍스처 R16G16B16A16_Float | 출력은 `HGUI::Image`로 표시. 조명 · 컬링 · 정렬은 없음(막힌 곳 없음) |
| 드로우 인자 | `HDrawArguments{Mesh, ObjectCBData, MaterialOverrides*}`, `HScreenDrawArguments{Material}`, `HRenderPassCBData`(카메라 · 해상도) | `SetRenderPassData`는 리스트의 업로드 할당자로 복사(영구 CB 없음) |
| 임포트 | `JGFBXAssetImporter`: 메시(`WriteMesh`, `SetData`에서 경계 상자 계산) + 임베디드 텍스처(stb_image 디코딩 → `R8G8B8A8_Unorm`, 밉 1, 이름 = 에셋 경로) → `.jgasset` JSON | 머터리얼 `ReadMaterial` 주석 상태(5-29). 호출 진입점 없음(5-31) |
| 기본 리소스 | `PDirectX12API::createDefaultResources`: 1×1 흰 텍스처, 프로퍼티 없는 Surface 머터리얼 | `HDirectXAPI::GetDefaultTexture()` 정적 접근자 |
