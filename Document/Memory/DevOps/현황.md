## 1. 역할과 범위

원칙 (결정 D1–D7, §3):

| 원칙 | 내용 |

| 엔진을 소스로 포함 (D3) | 게임 솔루션에 엔진 프로젝트 14개(09-30 R4 로 `Game` 이 빠짐, 그 전 15개)가 Engine 그룹으로 들어가고 산출물은 전부 `<Project>/Bin/<Config>/` |

GameProject 폴더 구조 (배치 1 이 만들고 배치 2 가 채운다):

```
<Engine>/Build/BatchFiles/CreateGameProject.bat <ProjectDir> [Name]    배치 1: 템플릿 복사 + 토큰 치환 (JGBuildTool -newproject=)
<Engine>/Build/BatchFiles/GenerateGameProjectFiles.bat <ProjectDir>    배치 2: JGHeaderTool -project= → JGBuildTool -project=
<Engine>/Build/Templates/GameProject/                                  템플릿 13 파일 (Source/ 밖에 둔다)

<ProjectDir>/
  <Name>.jgproject               { "Project": { Name, EngineRoot, GameModules:[<Name>], EditorModules:[<Name>Editor] } }
  GenerateProjectFiles.bat       배치 2 래퍼 (엔진 절대경로가 박혀 있다)
  .gitignore                     Bin/ Temp/ .vs/ *.sln <Name>.lua
  <Name>.lua · <Name>.sln        생성물 (Engine 그룹 14 + <Name>/Source 그룹 2)
  Bin/<Config>/                  엔진 + 게임 산출물, zlibstatic.lib · assimp-mt.lib · assimp-vc143-mt.dll (배치 2 가 복사)
  Content/                       게임 에셋. `/JGGame/<Content 기준 상대경로>` 로 로드, 시작 시 엔진 Content 다음에 전부 로드 (R7)
  Source/<Name>/                 <Name>.module.json · <Name>Defines.h · <Name>Module.h/.cpp · <Name>EntryActor.h/.cpp   (H<Name>Module, JG<Name>EntryActor)
  Source/<Name>Editor/           <Name>Editor.module.json · <Name>EditorDefines.h · <Name>EditorModule.h/.cpp        (H<Name>EditorModule)
  Temp/{CodeGen,Obj,ProjectFiles}/   CodeGen 에는 게임 모듈 것 + module_system_info.json(엔진 + 게임 SharedLib)
```

폴더 = 모듈 = DLL = premake 프로젝트 이름(D5). `MyGame` → `MyGame.dll` · `_MYGAME` · `MYGAME_API` · `HMyGameModule`, `MyGameEditor.dll` · `_MYGAMEEDITOR` · `HMyGameEditorModule`.
