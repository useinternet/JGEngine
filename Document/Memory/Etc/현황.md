### 1.3 구현 현황 상세

**흐름**

```
[모듈 DLL 또는 EXE의 .cpp 파일 범위]  static HAutoConsoleCommand X("area.action", "usage", "desc", &handler);
   생성자: 이 바이너리의 정적 목록(Head)에 연결만(풀·레지스트리·로그 사용 안 함, 정적 초기화 = LoadDll 중이라 Core 미연결)
      ↓ 모듈 DLL: GModuleGlobalSystem이 StartupModule 직후 IModuleInterface::RegisterAutoConsoleCommands → 그 DLL의 HAutoConsoleCommand::RegisterAll
      ↓ EXE: 레지스트리 생성자가 RegisterAll(GCoreSystem::Create), Destroy에서 UnregisterAll
GConsoleCommandGlobalSystem (Core 전역 시스템, 메인 스레드 전용)
   _commands: HHashMap<PString, HConsoleCommandDesc{Name, Usage, Description, HConsoleCommandDelegate}>   내장 help [name]
   Execute(line | tokens) 즉시 실행  /  Submit(line) → _pendingLines → Update() = ExecutePending() (스케줄러 모든 버킷 뒤 = 프레임 밖)
입력 A: JGDevConsole 위젯 → Enter → Submit          입력 B: JGConsole.exe argv[1..] → Execute(tokens) → 종료 코드 0/1
출력: JG_LOG → spdlog 싱크 3개(파일 jg_log.txt · stdout · PRecentLogSink) → 위젯이 GetRecentLogs로 표시
```
