1. 변경 — Source/Editor/JGEditor/JGEditor.cpp 한 파일(추가분만 Edit. Server 5-5 도 고칠 수 있는 파일)
---------------------------------------------------------------------------------------------
- EDITOR_ENGINE_MODULES 끝에 "GameFrameWorks"(7개: Graphics, GUI, Asset, DevStatistics, DevConsole, Devkit, GameFrameWorks).
  맨 뒤에 둔 이유: 게임 모듈이 연결하던 때와 순서가 같다 — 다른 엔진 모듈이 모두 올라간 뒤 시작하고, 종료 때는 게임 모듈 다음 · 창과
  다른 엔진 모듈보다 먼저 내린다. (요청 문구 "Graphics · GUI 뒤" 를 만족하면서 GFW 가 Asset · Devkit 보다 먼저 올라가는 새 순서를 만들지 않는다.)
- openSceneViewport 조건: JGGameInstance::HasInstance() == false 이면 반환 → _connectedProjectModules.empty() || HasInstance() == false 이면 반환.
  GFW StartupModule 이 JGGameInstance 를 만들어 init() 에서 s_instance 를 세우므로, GFW 를 늘 연결하면 프로젝트가 없어도 HasInstance() 가 true 다.
  그래서 "게임 모듈을 연결했는가"로 프로젝트 모드를 가른다(빈 월드 창이 저절로 뜨지 않게).
- disconnectProjectModules 의 DisconnectModule("GameFrameWorks") 는 그대로 둔다(게임 모듈 바로 뒤 · 창보다 먼저 내리는 순서).
  역순 해제 루프가 GameFrameWorks 를 한 번 더 부르지만 아무 일도 하지 않는다(아래 2).
- 주석 갱신: 엔진 모듈 목록(이유 · 순서 · 게임 모듈의 ConnectModule 은 true 만 받음), 씬 뷰포트 메뉴("월드가 없으면 안내 문구"), disconnectProjectModules.

2. 코드 확인
------------
- GModuleGlobalSystem::ConnectModule: 이미 연결된 모듈이면 true 만 돌려준다(참조 카운트 없음) → 게임 템플릿의 ConnectModule("GameFrameWorks") 는
  성공으로 지나가고 "Fail Connect GameFrameWorks Module..." Critical 이 나오지 않는다(프로젝트 모드 로그로 확인, 아래 5).
- DisconnectModule: 찾지 못하면 true → 두 번째 해제 무해. 로그에서 "GameFrameWorks module startup/shutdown" 은 각 1번.
- 위젯이 GFW 를 만지는 곳:
  · 프레임마다(OnUpdate · OnGenerateGUI): Scene Viewport · Gameplay DevView 는 HasInstance() → GetWorld() 순으로 보고 월드가 없으면
    "No world is loaded" 안내만 그린다 → 프로젝트 없는 에디터에서 메뉴로 열어도 안내 문구.
  · 종료: JGSceneViewport::OnShutdown 은 렌더러만 해제(Graphics 는 GUI 보다 늦게 내려감), JGGameplayDevView::OnShutdown 은 GameMaster 약한
    참조 Pin(이미 내려갔으면 null) 뒤 자기 관찰자만 정리, JGDataTableEditor 소멸자는 빈 함수. 종료 순서(프로젝트 모듈 → GFW → 창 → 엔진 모듈 역순
    = GUI 위젯 정리)는 프로젝트 모드에서 원래 그랬던 순서와 같고, 종료가 시작되면 프레임이 돌지 않는다 → 내려간 GFW 를 만지지 않는다.
