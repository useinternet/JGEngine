# 2026-09-29 작업 기록 — 아컴호러 카드 게임 기본판 룰·카드 데이터 정리

다른 AI 에이전트나 다음 세션이 이어서 작업할 수 있도록 현재 상황과 이번 작업 내용을 기록한다.

## 요청

"아컴호러 카드 게임을 레퍼런스로 엔진에 게임 모듈을 붙여 만들어 보려 한다. 아컴호러 폴더 안에 카드 데이터(설명, 키워드, 이미지 등)와 룰을 정리해 달라. 처음에는 코어 셋 한정(확장은 나중에)."
사용자가 참고한 사이트: https://ko.arkhamdb.com/

## 결정

- ArkhamDB 에 "코어"가 3종 있다: `core`(2016 오리지널), `rcore`(2020 개정판, 같은 카드에 매수만 증가), `core_2026`(2026-03, Chapter 2, 새 조사자·캠페인, 한국어는 재판 30종뿐). **사용자가 `core`(오리지널)를 선택**했다. 개정판은 매수(`quantity.revised_core`)만 붙였다.
- 폴더는 CLAUDE.md 규칙(문서는 Document)에 따라 `Document/아컴호러/`.
- 용어는 한국어판 참조 안내서의 공식 표기로 **모든 문서와 생성기를 통일**했다: 장막값, 능력(테스트·카드), 소모(commit), 전용 카드, 역할군, 주요목적/주요사건, 출현, 후퇴, 쓰러지다, 치워 두다, 조력자, 소모품(supplies), 거대한, `[combat]`=힘, `[wild]`=만능, 고대 표식. 기호 혼돈 토큰 4종은 한국어판에 이름이 없어(아이콘만) 영문 id 로 적는다. 대조표는 `02_용어_키워드.md` §6.

## 알아 둘 사실

- ArkhamDB 한국어 데이터는 **조우 카드 본문 번역이 없다**(본문 66장, 배경 글 다수). 이름·특성은 있다. arkhamdb-json-data 의 `translations/ko` 도 같다. `cards.json` 은 번역 없는 필드를 `ko: null` 로 둔다(한글이 없고 영문과 같으면 번역 없음으로 판정).
- ko 목록 API(`/api/public/cards/?encounter=1`)는 `type_name`·`faction_name`·`slot` 을 한국어로 주지만 단일 카드 API(`/api/public/card/<code>`)는 영어로 준다.
- 자유 격발 아이콘은 영문 텍스트가 `[fast]`, 한국어 텍스트가 `[free]`(같은 14종).
- 제외: `01000`(무작위 기본 약점 자리표시자), `98004`(로랜드 재판), ArkhamDB rcore 목록에 섞인 `01683`–`01695`(다른 확장 카드의 업그레이드 재판 13종).
- `01121a`(주요사건 1a) 와 `01121b`(적 가면 쓴 사냥꾼)는 한 장의 앞뒷면. 이미지로 확인.
- 기본판 매수는 ArkhamDB 기준: 단도·손전등·비상 물자 4장, 개정판 10장.
- 장소 기호·연결은 SCED(Tabletop Simulator 모드, `Chr1Z93/SCED-downloads`) GMNotes. 공개 면 24장 전부와 미공개 면 8장을 이미지로 대조했고 불일치 없음. 직접 대조: 01112 복도, 01125 아컴 강변, 01150 아컴의 숲(부정한 땅).
- 3편 권속 세트는 4종 중 **무작위**. 결말 효과는 ArkhamCards 캠페인 데이터(현행 가이드) 기준이고 2016 인쇄본과는 대조하지 못했다(06 §6 미검증 목록).
- 카드 텍스트는 효과를 기계가 읽을 수 없다. 엔진은 코드별 효과 구현 + `keywords`/`ability_icons` 보조 필드를 쓰는 구조로 가야 한다.
- 룰 원문 출처: arkham-cards-data `rules/ko/rules.json`(한국어 개정판 참조 안내서 기준, 2025-11-01 커밋), FAQ v2.5(2026-02) PDF 링크 확인됨(HTTP 200).

## 환경 메모

- `python` 은 스텁. 스크립트는 perl(JSON::PP). 병렬 에이전트가 돌 때 Bash 명령 하나에 15~20초가 걸려 대부분 백그라운드로 돌렸다.
- GitHub REST API 비인증 한도(시간당 60회)가 사무실 공인 IP 단위로 공유된다. 여러 에이전트가 쓰면 곧 막힌다. raw.githubusercontent.com 과 recursive tree 1회 호출을 쓴다.
