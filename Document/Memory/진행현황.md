## 2. 전 트랙 공통 우선순위

1. **한 커밋으로 묶기.** GameFrameWorks Phase 1, Network Phase 0~4, DevConsole Phase 0~4, GameModule, Memory 4-1, Graphics 5-26(3)과 문서 재편이 한 작업 트리에 미커밋으로 섞여 있다. `Core/ConsoleCommand/`(미추적)에 GameFrameWorks·NetCommands·JGConsole이 의존하므로 파일 단위 분리 커밋은 빌드를 깨뜨린다. 5절 체크리스트를 따른다.
2. **공유 파일 조율.** 4절 표의 파일은 두 트랙 이상이 고친다. 착수 전 `git status`로 겹침을 확인하고 상대 트랙 현황.md의 의존/충돌 절을 읽는다.
3. **결정 대기 항목 처리.** 3절 통합 표. Graphics 5-30과 Server Phase 5 여부가 가장 많은 후속 항목을 막고 있다.
4. **커밋 뒤 회귀 1회.** 커밋된 Bin으로 `gmtest`, `net.test all`, `console.selftest`, 2프로세스 스크립트, 런처 60초 실행(종료 코드 0, live 0)을 한 번 돌려 기준선을 남긴다.
