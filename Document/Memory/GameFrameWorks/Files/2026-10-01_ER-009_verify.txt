      D3D12 디버그 레이어(D3D12SDKLayers.dll)의 스레드 풀 콜백 'Internal D3D12 Sync Thread' 가 돌 때마다 옛 방식 스레드 이름 예외(0x406D1388)를 올려
      디버그 이벤트가 끊이지 않는다 → 시간 초과 갈래에 들어가지 못해 WM_CLOSE 를 보내지 않는다.
      진단(스크래치패드 사본에 이벤트 수 세기 추가, NetDuel 호스트 20초): exception 2259 (0x406D1388 x 2256, 0x80000003 x 1, 0xE06D7363 x 2), create thread 56, load dll 126.
      0x406D1388 #600 의 콜스택: KERNELBASE!RaiseException ← D3D12SDKLayers.dll (여러 프레임) ← ntdll!TpCallbackMayRunLong ← BaseThreadInitThunk. 엔진 코드에는 스레드 이름 설정이 없다(grep 0).
      스레드 이름 원문(앞 12번 + 600번째): #1 'NVFBCAsyncThread'(대상 -1, 시작 때 한 번), #2~#12 · #600 'Internal D3D12 Sync Thread'(같은 스레드).
