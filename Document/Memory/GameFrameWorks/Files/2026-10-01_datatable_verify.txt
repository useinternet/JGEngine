== 3. V2 editor, real window input (worktree editor, JG_UITEST=1) ==
Input path: PostMessage WM_MOUSEMOVE/BUTTON/KEY/CHAR to the launcher window (scratchpad dt_ui.ps1);
  Ctrl/Shift via AttachThreadInput + SetKeyboardState (+ keyup after); worktree-only hook so ImGui uses the main viewport
  for hover (otherwise the real cursor position decides and posted clicks are dropped). Real mouse/keyboard unaffected.
Table: /JGEngine/DataTableTest/Sample.jgasset - Count Int, Label String, Rate Float (default 1.0, Min 0),
  Enabled Bool (default true), Kind Enum [A,B,C], Next RowRef (same table).
Checked (capture names in scratchpad v2/, selected ones copied here):
  - New... dialog (Content /JGEngine/, path, key column) -> file created, AssetPath = token path, Name "JGDataTable"
  - + Column dialog (Count Int, Label String) -> Save
  - external edit while clean -> "Reloaded /JGEngine/DataTableTest/Sample.jgasset (changed on disk)"
  - restart -> layout reopened the window, "Open table..." lists the asset, opens it
  - + Row; Ctrl+V of Excel-style TSV 3x7 (Korean, quoted cell with "" , TRUE/FALSE/true, empty cell) -> "Pasted 3 x 7 cell(s)"   [v2_paste_tsv]
  - type-to-edit (42), Korean committed characters via WM_CHAR ("한글 입력"), Space toggles Bool
  - Enum combo below the cell (double click, F2) -> pick; RowRef combo lists (none), Row_A, Row_B, Row_C                 [v2_rowref_combo]
  - double click text cell -> edit keeps text; Esc cancels
  - duplicate key -> red border + "[Error] row 3, Id: key 'Row_A' is a duplicate of row 1" + RowRef warning,
    Save -> "not saved: key 'Row_A' is a duplicate of row 1 (row 3)"                                                 [v2_validation_blocks_save]
  - Undo / Redo (toolbar + Ctrl+Z) -> status "Undo: Rename key" / "Redo: Rename key"
  - header right-click menu (sort asc/desc, clear, apply sort, insert/move/delete column, properties)                    [v2_header_menu]
  - Sort descending: view 42/12/3, row numbers keep file order, status "view sorted or filtered (file order unchanged)"
  - Filter "한글" -> "1 of 3 rows"; clear; Clear sort -> file order                                                        [v2_filter_korean]
  - drag-select 3x3 + Ctrl+C -> clipboard (Get-Clipboard -Raw):
      3<TAB>첫 행<TAB>1.5<CRLF>
      42<TAB>"둘째 ""따옴표"""<TAB>0.25<CRLF>
      12<TAB>한글 입력<TAB>2.0<CRLF>
    (cell with quotes is wrapped and inner quotes doubled, same as Excel / Google Sheets)
  - Save -> file: rows one value per line, Korean UTF-8, Rate 1.5 / 0.25 / 2.0, Default 1.0, Min 0.0, key order Id..Next
  - close (WM_CLOSE) -> exit 0, [error] 0, live blocks 0 -> restart -> reopen -> same values
  - column panel (header click): Label String -> Int, Apply -> "3 value(s) could not convert to Int and were reset to
    the default (Ctrl+Z to undo)" -> Undo restores String + values                                                       [v2_column_panel, v2_type_change_reset]
  - tab close: clean -> closes at once ("Closed <path>"); unsaved -> "Close Table" Save and close / Discard / Cancel;
    Cancel keeps the tab; Discard closes, file unchanged                                                                 [v2_close_unsaved]
  - external edit while unsaved -> bar "The file changed on disk while you have unsaved changes." with
    "Reload (discard mine)" / "Keep mine"; Keep mine + Save -> file has my values (3, 77, 12);
    Reload -> disk values, history cleared                                                                               [v2_external_change_bar]
  - cell right-click menu (insert above/below, duplicate, delete rows, move rows, copy/cut/paste, reset to default)      [v2_cell_menu]
  - Duplicate row -> "Row_B_copy" below + status "Duplicated row 'Row_B' as 'Row_B_copy'"; Ctrl+- -> "Deleted 1 row(s)"
