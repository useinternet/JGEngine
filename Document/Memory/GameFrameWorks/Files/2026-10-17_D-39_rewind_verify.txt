  RewindTo(name, random): 글을 먼저 읽어 보고 실패하면 아무것도 안 바꿈 → 지점 상태로 읽어 들임 → Sequence · Seed · 지점 목록 · (KeepCurrent 면) 난수는 되감기 직전 값,
  등록부는 KeepIssuedGenerations(되감기 직전 등록부).
  직렬화: WriteJson · ToJsonString = 지점 사본까지("RewindPoints": [{Name, State}]), Checksum = 지점 이름 · 해시만("RewindPointNames" · "RewindPointHashes"),
  지점 사본 자신 = 지점 칸 없음. 지점이 없으면 아무 칸도 쓰지 않음 → 지점 없는 게임의 상태 JSON 은 1 판과 같은 칸(버전 번호만 2).
  FNV-1a 를 hashGameplayText 하나로 모음. "State" 는 HStateJsonWriter 로 바로 써서 JSON 트리를 복사하지 않음.
GameMaster/State/GameplayEntityRegistry.h · .cpp
  GenerationFloors(인덱스별 다음에 낼 세대의 바닥 — 되감기만 채움, 비면 JSON 에 안 씀). Create 가 재사용 인덱스에 바닥을 적용.
  KeepIssuedGenerations(before): 바닥 = max(바닥, before 의 바닥, before 가 다음에 낼 세대), 지점 뒤에 생긴 인덱스는 빈 칸 + 재사용 대기(오름차순).
  → 지점 때 살아 있던 엔티티는 원래 번호, 지점 뒤에 생긴 번호는 죽은 번호(다시 나오지 않음).
