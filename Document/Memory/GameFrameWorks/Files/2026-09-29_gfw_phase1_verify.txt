===== 5. 바뀐 동작 (게임 규칙 작성자가 알아야 할 것) =====
- 트리거 React 는 이벤트를 낸 단계(효과 · 핸들러 · 페이즈 전이)가 끝난 뒤에 불리고, HGameplayTriggerContext(Enqueue 만, 상태 const)를 받는다

- Add<T> 는 T* (죽은 ID 면 nullptr). 보드 · 영역 쓰기는 HGameplayState::SetBoardPosition · MoveToZone
- const HGameplayState 의 Find/Get/Table 은 const
- 이벤트 순서 · 체크섬 값이 전과 달라졌다 (같은 코드끼리는 결정론 유지, 2 프로세스 확인)
