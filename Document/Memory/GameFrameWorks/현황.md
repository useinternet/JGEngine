### 10.4 함정 · 주의

| 함정 | 내용 |
|---|---|
| 게임 위젯은 게임 DLL 코드 | `JGGameWidget` 파생 클래스 · 버튼 람다는 게임 모듈 DLL 에 있다. 게임 모듈 `ShutdownModule` 에서 `GetUI()->ClearAllWidgets()` 로 먼저 내린다(엔진도 게임 인스턴스 종료 때 남은 위젯을 내린다 — DLL 은 종료 때 내려가지 않아 안전하지만 순서를 분명히) |
| 훅 안에서 스택 바꾸기 | 버튼 `OnClicked` · `OnActivated` 안에서 Push · `DeactivateWidget` 해도 된다(입력 전달 · Update 는 스냅숏으로 돈다). 스택이 바뀌면 호버 · 캡처를 푼다 |
| 다시 Push | 빠진 위젯은 `OnShutdown` 뒤 트리가 비워진다(루트 불투명도 · 그리기 변환도 처음으로). 같은 객체를 다시 Push 하면 `OnInitialize` 부터 다시(트리를 다시 만든다). 닫힘 전환 중에 같은 객체를 Push 하면 예외 — 지금 모습에서 다시 열린다(`OnInitialize` · `OnShutdown` 없음, 로그 "- reopened while closing"). 메뉴처럼 자주 열고 닫는 화면은 한 객체를 들고 `PushWidgetInstance` 로 다시 올리면 닫히다 다시 열기가 자연스럽다 |
| 같은 스택의 아래 위젯 | 그려지지 않고 입력도 없다(CommonUI 스택과 같음 — 맨 위가 열림 전환 중일 때만 덮여 멈춘 모습으로 그린다). 다른 레이어의 맨 위 위젯은 계속 활성이다 — HUD 는 메뉴가 떠도 활성(입력만 Menu 위젯이 막는다) |
| 비활성 요소 | 판정은 된다(아래 · 월드를 막는다). 꺼진 부모 아래 자식은 판정에서 부모로 바뀌고, 버튼은 비활성 모습으로 그린다 |
| 리플렉션 | `JGGameWidget` 은 JGCLASS 다(`GameWidget.generation.h`). 게임 파생도 JGCLASS 로 두면 `PushWidgetByClass` 로 만들 수 있다. 셀프 테스트의 리플렉션 없는 파생은 타입 이름이 `JGGameWidget` 으로 찍힌다 |
| 색 · 글꼴 | 화면 색이 옅던 문제(FP16 선형 → sRGB, D-3)는 10-01 Graphics 5-14(8비트 sRGB 출력, 커밋 `efba16a`)로 해소 — 게임 UI 색은 코드 값 그대로 보인다(GG-H11 닫음 — 메인 엔진 검증 게임 V2 20단계 · D3D12 메시지 0). 개발용 기본 글꼴은 시스템 맑은 고딕 — 배포 금지, 게임은 자기 글꼴을 `LoadFont` |
| Esc | Scene Viewport 창에 포커스가 있을 때만 게임 UI 로 간다. 다른 ImGui 창(DevConsole 입력줄 등)에 포커스가 있으면 그 창이 받는다. 입력란에 포커스가 있으면 첫 Esc 는 포커스 해제다 |
| 글자 입력 · ImGui | 키보드 내비게이션(`NavEnableKeyboard`)이 켜져 있어 방향 · Tab · Enter · Space 를 ImGui 가 창 안 항목 이동 · 실행에 쓴다 → 호스트가 입력 중 매 프레임 `HGUI::ClaimTextEditKeys`(내부 API `SetKeyOwner`). IME 창 자리도 매 프레임 `HGUI::SetTextInputPosition`(ImGui 가 프레임마다 지운다). 글자 큐는 16비트(BMP 밖은 U+FFFD → 호스트가 버림, GG-H24). ImGui 를 올리면 GUI.cpp 의 이 두 내부 API 를 다시 본다 |
| 줄바꿈 · 배율 | 줄 나누기 · 측정은 논리 단위(`MeasureContent` 는 배율과 무관). 그리기는 글리프를 화면 배율의 정수 픽셀 크기로 래스터화하되 자리는 논리 배치 × 배율이라, 배율이 정수 크기와 어긋나도 줄이 요소 폭을 넘지 않는다(글자 간격이 1px 안에서 달라질 수 있다) |

### 11.4 함정 · 주의

구현 중 확인한 함정(PString 빈 글 비교 · `ToLower` assert · `JGEnum` 이름 찾기 · 헤더 도구 문자열 토큰 · ImGui 팝업 ID 범위 · dllexport 복사 연산 · `SameLine` 인자 · PostMessage 자동 입력)은 **설계 §14-3** 에 표로 있다. 그 밖에:

| 함정 | 근거 | 대응 |
|---|---|---|
| `PJsonData` 읽기는 값을 원본에서 옮긴다 | `Core/FileIO/Json.h` `FindMember` · `GetData` | 키마다 한 번만 읽고, 종류는 `GetValueType` 으로 먼저 묻는다 |
| `PJson::ToObject` 는 파싱 오류에도 true(호출 11곳) | `Json.cpp` | 그대로 둔다. 오류가 필요한 곳은 `ToObjectWithError`(지금은 `LoadObject` 만) |
| 파일 I/O 는 좁은 문자 경로 | `Core/FileIO/FileHelper.cpp` | 테이블 경로는 ASCII 만(`MakeDataTableTokenPath` 가 거부) |
| 앱 종료는 저장 안 된 변경을 묻지 않는다 | 엔진에 닫기 요청 훅 없음 | 창 X 로 닫으면 탭이 남는다(위젯 인스턴스 유지). 앱 종료 확인은 보류 DT-H9 |
| 게임 모듈에서 `Data/DataTable.h` 를 쓰려면 `Asset` 의존 필요 | 게임 템플릿 의존 = Core · GameFrameWorks, include 경로 전이 없음(GFW C-1) | 게임 `module.json` 에 `Asset` 추가(설계 §15) |
