## 2. 시험 전용 규칙 (이 절에서만 등록)

| 명령 | 하는 일 | 검증(Validate) |
|---|---|---|
| `NetMark` | 핸들러에서 `ctx.MarkRewindPoint("NetTurn")` | 행동자 차례 |
| `NetRewind` | `Params[0]` = 난수(되돌림 / 이어 감), `Params[1]` = 부르는 곳(0 핸들러에서 바로 · 1 효과를 넣어 효과에서). `RewindTo("NetTurn", 난수)` 뒤 **남길 변화**: 행동자 유닛을 다시 찾아 Hp −1 | 행동자 차례 + 지점 있음 |
| `NetClear` | `ctx.ClearRewindPoint("NetTurn")` | 행동자 차례 + 지점 있음 |

- 차례는 `EndTurn` 명령으로만 넘어가므로 한 행동자가 표시 → 소환 → 공격 → 되감기를 이어서 낼 수 있다.
- 각본 판(3절)에서는 이 셋을 에이전트 후보(Enumerate)에 넣지 않는다(시험이 손으로 낸다). 무작위 판(4절)에서는 넣는다.

## 3. 각본 판 — 방장 1 + 참가자 2, 나중에 1 명 더

| # | 장면 | 확인 |
|---|---|---|
| 1 | 판 시작, 참가자 1(slot 1) 유닛 차례까지 진행 | 모두 체크섬 같음 |
| 2 | 참가자 1 `NetMark` | 모든 기계에 지점이 있다 · 체크섬 같음 |
| 3 | 참가자 1 `NetSummon` → 토큰 T, `NetStrike`(난수 피해) | 모든 기계에 T |
| 4 | 참가자 1 `NetRewind`(이어 감 · 효과에서)를 보내고, 곧바로 T 를 노린 `NetStrike` 를 보낸다(줄에 섬) | 되감기는 모든 기계에서 같다 · **T 는 모든 기계에서 죽은 번호** · 줄에 선 공격은 보내기 전 다시 검증되어 "invalid target" 으로 거절(`OnLocalCommandRejected` 1번, 방장 순번은 되감기 1 만큼만) · 순번은 되감지 않음(되감기 전 + 1) · 남길 변화(Hp −1)가 모든 기계에 · 지점은 남아 있음 · 불일치 0 |
| 5 | 참가자 1 `NetSummon` → 토큰 T2 | T2 ≠ T, T 는 계속 죽음 · 체크섬 같음 |
| 6 | 새 참가자 3 이 판 도중 입장(문서) — 지점이 있는 채로 | 입장 직후 체크섬 · 마지막 적용 순번이 방장과 같다 · 입장한 쪽에도 지점이 있다 |
| 7 | 참가자 1 `NetRewind`(되돌림 · 핸들러에서) | 들어온 참가자 3 까지 모두 같다 · T2 죽음 |
| 8 | 참가자 1 `NetSummon` | 모두 같은 번호를 낸다 — 입장 문서에 "지금까지 낸 가장 큰 세대" 칸이 실려 갔다는 확인(빠졌으면 참가자 3 만 다른 번호 → 불일치로 잡힌다) |
| 9 | 참가자 2 복제본을 고의로 바꾼다 → 다음 승인에서 재동기 문서 | 불일치 1번 검출 · 문서로 복구 뒤 같음(지점이 든 재동기 문서) |
| 10 | 참가자 1 `NetClear` | 모든 기계에서 지점 없음 · 체크섬 같음. 그 뒤 `NetRewind` 는 로컬 검증에서 거절 |
| 11 | 끝까지 무작위로 조금 더 진행 | 모두 불일치 0 · 마지막 적용 순번 = 방장 순번 · 체크섬 같음 |
