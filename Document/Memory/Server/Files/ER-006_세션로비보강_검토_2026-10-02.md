## 3. 문제가 실제로 생기는 조건

| 흐름 | 호스트 세션 상태 | 시작 전 퇴장 | 근거 |
|---|---|---|---|
| 월드 로드와 함께 시작 (엔진 템플릿 규약 · NetDuel) | Host 를 누르는 순간 이미 Playing(시작된 게임을 이어받음) | 생기지 않는다 | 5-5 검증 관찰(`2026-10-02_5-5_lobby_results.txt` "ER-006 관련 관찰") |
| 로비 먼저 → 방장이 시작 (게임의 "같이 하기") | 방을 연 뒤 시작을 누를 때까지 **Ready** | **생긴다** — 들어왔다 나간 자리가 토큰째 남는다 | 게임 방 화면이 시작 때 `bConnected == false` 자리를 건너뛰는 우회를 쓴다 |
| 판이 끝나 로비로 돌아옴 (메뉴 월드를 다시 로드) | 월드를 내리며 GameMaster 를 떼면 Ready 로 돌아간다(`onUnbound`, `GameplayHostSession.cpp:240`) | 지난 판에 끊긴 자리가 토큰째 남아 있다 — 같은 문제 | 코드 경로 |

따라서 규칙은 "호스트 세션이 Playing 이 아닐 때 끊긴 자리는 비운다"가 맞다. 끊기는 순간과 Ready 로 돌아오는 순간에 모두 적용한다.

## 8. 게임 쪽에 알릴 것

- 요청서 현황표의 "세션 틱" 행은 낡았다. 엔진 5-1 이 끝나 게임 인스턴스가 세션을 갖고 돌린다(게임도 이미 그렇게 쓴다).
- ① 이 들어가면 시작 전에 나간 자리는 슬롯 표에서 이름이 빈 자리로 온다. 목록 화면은 `bConnected == false` 이고 이름이 빈 자리를 "빈 자리"로 보이면 된다.
- 판이 끝나고 로비로 돌아왔을 때도 지난 판에 끊긴 자리가 비워진다.
