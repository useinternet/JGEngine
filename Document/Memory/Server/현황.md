# Server(네트워크 · 리슨 서버) 현황

분야: Server — GameFrameWorks 위의 리슨 서버(호스트 권한 명령 중계 + 결정론 복제). 갱신 2026-09-30.
**한 줄 요약:** Phase 0–4(커널 준비 · 전송 · 세션 · 복구 · 2 프로세스 결정론)는 구현 · 검증 완료(`gmtest` 111/111 · `net.test all` 66/66 · 2 프로세스 체크섬 동일)이고 **전부 미커밋**. Phase 5(월드 연결)는 미착수이며 사용자 착수 지시가 없다(지시는 "Phase 4 까지").

## 1. 역할과 범위

| 구분 | 내용 |
|---|---|
| 목적 | 호스트 한 대가 서버 겸 플레이어인 리슨 서버로 턴제 커널 `PGameMaster` 를 여러 기계에 복제한다 |
| 방식 (방안 A) | 호스트의 `PGameMaster` 만 명령을 승인 → `CommandAccepted{seq, slot, 명령, 체크섬}` 방송 → 클라는 복제 `PGameMaster` 에 같은 명령을 `Submit` 하고 체크섬을 비교 |
| 범위 안 | 전송(TCP · 루프백) · 세션(호스트 · 클라) · 메시지 · 입장 / 재접속 / 재동기 · 호스트 AI 구동 · 헤드리스 검증 명령 |
| 범위 밖 | 실시간 월드(자유 이동) 액터 복제 · 은닉 정보(PvP) · 매치메이킹(직접 IP · LAN 만, 인터넷은 호스트가 포트 개방) |
| 원칙 | 싱글플레이도 같은 세션 경로(Standalone 호스트 세션)를 탄다. 게임 규칙 · 연출 코드는 넷 모드를 모른다. `PGameMaster::Submit` 은 세션만 부른다 |

### 아키텍처 한 눈에

| 계층 | 호스트 (Standalone · ListenServer) | 클라 (Client) |
|---|---|---|
| 입력 | 컨트롤러 · AI(호스트만 구동, 한 Tick 최대 64 명령) → `SubmitLocal` | 컨트롤러 → `SubmitLocal` → `CommandRequest` 전송. 한 번에 하나만 보내고 나머지는 `Queued` |
| 세션 | `PGameplayHostSession`: 도착 순 줄 세우기 → 소유 검사("not your actor") → `PGameMaster::Submit` → `CommandAccepted` 방송 / `CommandRejected` 회신 | `PGameplayClientSession`: 승인을 받은 순서대로 복제본에 `Submit` → 순번 · 체크섬 비교 → 어긋나면 양쪽 JSON 덤프 · `ResyncRequest` |
| 커널 | `PGameMaster` (권한) | `PGameMaster` (복제). 로컬 `Validate` 로 틀린 명령은 왕복 없이 거절 |
| 전송 | `INetTransport` — `PNetTcpTransport` · `PNetLoopbackTransport`. 바이트만 안다, 메인 스레드 Poll | 같음 |
| 복구 | 진행 중 입장 · 재접속(같은 토큰 = 같은 슬롯) · 재동기에 `Document`(zlib 저장 문서) 송신 | `Welcome{bStarted}` 뒤 문서 → `ImportDocument` → 문서 `Sequence` 초과 승인만 적용 |
| 시작 | 게임 코드가 초기 상태 구성 후 `StartGame(seed)` → `StartGame{시드, 지문, 초기 상태}` 방송 | 받은 초기 상태로 같은 `Start(seed)`. 규칙 지문이 다르면 스스로 종료 |

| 메시지 · 규약 | 값 |
|---|---|
| 메시지 12종 (`EGameplayNetMessage`) | Hello · Welcome · Refuse · SlotChanged · StartGame · CommandRequest · CommandAccepted · CommandRejected · ResyncRequest · Document · Travel · Ping |
| 바이트 형식 | `[종류 u8][플래그 u8][본문 JSON]`, 문서만 zlib(`[원래 크기 u32][압축]`), Ping 은 본문 없음 |
| 핸드셰이크 | `Hello{프로토콜 버전 1, 상태 스키마, 이름, 토큰}` — 다르면 `Refuse`. 규칙 지문은 `Welcome` · `StartGame` 에 실어 클라가 비교 |
| 순번 | 상태의 `Sequence`(검증 통과 명령마다 1 증가). 세션 전용 카운터 없음 |
| 세션 상태 | `Connecting → Ready → Playing ⇄ Resyncing → Closed`. `SubmitLocal` 결과 `Rejected · Executed · PendingChoice · Sent · Queued` |
| 설정 (`HGameplaySessionConfig`) | `PlayerName` · `MaxPlayers`=4 · `bLocalPlayer` · `PingInterval`=1 s · `TimeoutSeconds`=10 s · `DesyncDumpDirectory`="NetDesync" |

## 5. 알려진 함정 / 주의사항

| 항목 | 내용 |
|---|---|
| Winsock 포함 순서 | PCH 가 `d3d12.h` · `Rpc.h` 로 `Windows.h` 를 `WIN32_LEAN_AND_MEAN` 없이 들여와 구 `winsock.h` 가 먼저 들어간다. 그 뒤 `winsock2.h` 는 오류 102건(`Files/2026-09-29_winsock_include_probe.txt`). **구현은 PCH 를 고치지 않고** `NetTcpTransport.cpp` 한 파일에서 Winsock 1.1 을 그대로 쓴다(`SD_SEND` 직접 정의, `ws2_32.lib` pragma). `_WINSOCKAPI_` 가 없으면(LEAN_AND_MEAN 도입 시) 같은 파일이 `winsock2.h` 를 넣는다. 헤더에는 Winsock 을 넣지 않는다(소켓은 `uint64`) |
| 공유 PCH 변경 금지 | 바꾸면 16 프로젝트 전체 재빌드 + 다른 세션 빌드와 충돌 |
| 2 프로세스 테스트 유지 | 한 프로세스 테스트는 문자열 테이블 · 리플렉션 목록 · 정적 변수를 공유해 기계 간 차이를 가린다. GameMaster 를 바꿨으면 `run_two_process.sh` 까지 돈다 |
| 수신 주소 | 테스트는 127.0.0.1 로 묶는다(`net.host -bind=` 기본). 모든 인터페이스(`-bind=` 빈 값)로 열면 Windows 방화벽 확인 창 |
| TCP 정상 종료 | 받지 않은 데이터가 남은 채 `closesocket` 하면 RST 로 상대가 데이터를 잃는다. 전송은 다 보냄 → `shutdown(SD_SEND)` → 상대가 닫을 때까지 읽어 버림 → 닫기. `Close` 뒤에도 `HasPendingSends()` 가 false 될 때까지 `Tick` |
| 디버그 도구 abort | 디버그 빌드 JGConsole 은 CRT abort 대화상자에서 멈춘다 → 스크립트는 `timeout 400` 으로 감싼다. 숫자 인자는 예외 없는 파서만 쓴다(`std::stoull` 금지) |
| GameMaster 공유 파일 | GameMaster.cpp · GameplayRuleEngine.cpp · GameplayState.h · GameMasterSelfTest.cpp 는 GFW 트랙과 함께 고친다. 착수 전 `git status --porcelain -- Source/Runtime/GameFrameWorks` 로 겹침 확인 후 그 세션과 조율(09-29 에 한 번 3-way 병합) |
| 결정론 규칙 | 규칙 코드는 상태 + 명령 외 입력(시계 · 로컬 설정 · 연출 상태) 금지, 부동소수 금지, 컴포넌트 필드 전부 기본값 초기화(미초기화 값이 JSON 체크섬에 실린다. 디버그 채움 패턴 때문에 릴리스에서야 드러남) |
| 체크섬 비용 | 상태 전체 JSON + FNV. 301 엔티티 5–6.6 ms(디버그), 명령마다 전원이 한 번 |
| 새 워크트리 PreBuild | 첫 실행은 `Temp/CodeGen/module_system_info.json` 이 없어 코드젠이 비고 `Asset.generation.h` C1083 → PreBuild 두 번 |
| JGConsole 과 GC | GC 를 돌리지 않아 16 B 클래스가 자란다(디버그 컨테이너 프록시). 종료 시 live blocks 0 이면 정상 |
| 명령 위치 규칙 | 사용자 결정(DevConsole): 모듈의 테스트 명령은 그 모듈에 선언. `net.host` / `net.join` 은 호스트 · 클라 루프를 계속 돌아 에디터 콘솔에서 실행되면 에디터가 멈추므로 JGConsole 에 남긴다 |
