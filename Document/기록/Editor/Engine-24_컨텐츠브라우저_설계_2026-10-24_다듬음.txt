--why (줄마다 따로 — 대시보드에서 한 줄씩 나뉜다)

컨텐츠 브라우저(Engine-22) 설계도를 확인받으려 합니다.
사용자 말씀: "컨텐츠 브라우저 만들기 ( 언리얼 레퍼런스 ) … 메시든 텍스쳐든 뭐든"
지금 에디터에는 에셋을 둘러볼 창이 없습니다.
데이터 테이블만 Data Table Editor 의 Open 목록에서 열 수 있습니다. 메시 · 텍스처는 코드에 경로 글자로만 적습니다.
FBX 가져오기 함수는 있지만 아무 곳에서도 부르지 않습니다.
만들 것: 에디터에 새 Content Browser 창을 둡니다.
- 왼쪽: 폴더 트리(/JGEngine/ · /JGGame/)
- 가운데: 타일. 텍스처는 실제 그림으로 보입니다.
- 할 수 있는 일: 찾기 · 종류 칩으로 거르기 · 원본 .fbx 가져오기 · 데이터 테이블 더블클릭으로 열기 · 경로 복사
나눠 맡기: 화면은 JGEditor 가 그립니다. 폴더 읽기와 가져오기는 GameFrameWork 에 함수 둘(ListAssetFolder · ImportAssetFile)을 더해 맡깁니다. GUI 에는 트리 · 더블클릭용 감싸개 셋을 더합니다. 약 2.5일.
① 시안 A(트리 · 타일 · 아래 세부): 텍스처를 그림으로 보고 고르기 쉽고, 씬 뷰포트 아래 넓은 도킹 자리에 맞습니다. 대신 파일이 아주 많으면 표보다 훑기 어렵습니다.
② 시안 B(트리 · 목록 · 오른쪽 세부): 파일이 많아도 표로 훑기 좋습니다. 대신 썸네일이 없어 텍스처를 고르기 어렵고, 세 칸이라 좁은 자리에서 답답합니다.
③ 시안 C(아래 서랍): 씬 뷰포트 아래에 낮게 붙어 자리를 적게 씁니다. 대신 트리가 없어 폴더가 깊으면 오가기 어렵고, 세부를 보여 줄 자리가 없습니다.
첫 판에서 미루는 것: 끌어 놓기 · 이름 바꾸기 · 지우기 · 메시 썸네일 · 목록 보기 · 파일 고르기 창
PNG 가져오기는 언리얼 에셋 가져오기(Engine-26)에서 따로 합니다.
권고: ① 시안 A 와 위 첫 판 범위. 텍스처 · 메시를 고르는 일이 많고, 미룬 기능은 이 구조 위에 나중에 더할 수 있기 때문입니다.
예제 — 에셋 목록 얻기, 지금(데이터 테이블만 얻음):
```cpp
// 지금: 데이터 테이블만, 폴더 없이
HList<HDataTableAssetEntry> tables;
GetLoadedDataTables(tables);
for (const HDataTableAssetEntry& entry : tables)
{
	if (HGUI::Selectable(entry.TokenPath, findTab(entry.TokenPath) != nullptr))
	{
		OpenTable(entry.TokenPath);
	}
}
```
예제 — 에셋 목록 얻기, 바뀐 뒤(한 폴더의 하위 폴더 · 에셋 · 원본 파일):
```cpp
// 바뀐 뒤: 한 폴더의 하위 폴더 · 에셋 · 원본 파일
HList<HAssetFolderEntry> entries;
ListAssetFolder("/JGGame/Meshes", entries);
for (const HAssetFolderEntry& entry : entries)
{
	// entry.Kind = Folder · Asset · Source, entry.TokenPath, entry.ClassName(예: JGStaticMesh)
	drawTile(entry);
}
```
예제 — 가져오기, 지금(가져오기 클래스만 있고 부르는 곳이 없음):
```cpp
// 지금: 인자를 직접 꾸려 가져오기 클래스를 불러야 하고, 새 에셋은 다음 실행에야 에셋 DB 에 올라온다
class PFBXAssetImportArguments : public PAssetImportArguments
{
	EFBXAssetImportFlags Flags;      // SrcPath(원본 파일) · DestPath(저장 폴더, 디스크 경로)는 기반 클래스
};
virtual bool JGFBXAssetImporter::Import(PSharedPtr<PAssetImportArguments> inArgs);
```
예제 — 가져오기, 바뀐 뒤(원본 파일과 저장 폴더만 주면 됨):
```cpp
// 바뀐 뒤: 원본 파일과 저장 폴더(토큰 경로)만 주면 확장자로 가져오기 클래스를 고르고, 새 에셋을 바로 올린다
HAssetImportResult result;
if (ImportAssetFile(source.TokenPath, "/JGGame/Meshes", &result) == false)
{
	_statusText = result.Error;
}
// result.CreatedAssets(새 .jgasset 토큰 경로)는 다음 프레임 브라우저에 보인다
```
