# 언리얼 컨텐츠 브라우저 살펴보기 (Engine-23)

## 결론

- 언리얼 컨텐츠 브라우저의 뼈대는 **폴더 트리 → 에셋 목록(타일 · 목록 · 표) → 열기 · 끌어 놓기**이고, 썸네일 · 찾기 문법 · 필터 · 기록 · 우클릭 메뉴 · 컬렉션 · 여러 브라우저는 그 위에 얹힌 것이다.
- 지금 JGEngine 에는 에셋 창이 없다. 에셋 DB(`GAssetDatabase`) · 경로 규칙(`HAssetPath`) · 에셋 클래스 셋 · FBX 가져오기는 있어서, **폴더 읽기 · 가져오기 함수 둘과 HGUI 감싸개 셋만 더하면** 뼈대(트리 · 타일 · 찾기 · 종류 거르기 · 가져오기 · 더블클릭 열기)를 만들 수 있다.
- 첫 판 범위는 아래 표의 "넣음" 줄이다. 끌어 놓기 · 이름 바꾸기 · 지우기 · 메시 썸네일 · 목록 보기 · 파일 고르기 창은 미룬다.

살펴본 것: 이 PC 에 깔린 UE 5.7 의 컨텐츠 브라우저 소스(`C:/Program Files/Epic Games/UE_5.7/Engine/Source/Editor/ContentBrowser/` · `ContentBrowserData/` · `UnrealEd/` 의 썸네일 부분 · `Plugins/Editor/ContentBrowser/ContentBrowserAssetDataSource/`)와 JGEngine 소스(`Source/Runtime/GameFrameWork/Asset/` · `Data/DataTableAssets.h` · `Source/Editor/JGEditor/` · `Source/Runtime/GUI/GUI.h`).
언리얼 에디터는 띄우지 않았다 — 언리얼 프로젝트 `C:/Develop/Start` 는 에디터로 연 기록이 없어(`Saved/Config` 없음) 처음부터 셰이더를 컴파일해야 하고, 사용자 화면을 오래 가린다. 화면 시안은 직접 그렸다(`Saved/UIShots/Engine-24_컨텐츠브라우저_시안비교.png`).

## 언리얼 구조에서 가져올 것

- **UI 와 데이터 층을 나눈다.** 언리얼 UI 는 항목(가상 경로 · 이름 · 속성)만 알고, 나열 · 열기 · 가져오기는 데이터 소스가 한다. JGEngine 은 이 나눔을 모듈로 한다 — 화면은 JGEditor 의 `JGContentBrowser`, 나열 · 가져오기는 GameFrameWork 함수(`ListAssetFolder` · `ImportAssetFile`).
- **경로 바꾸기는 한 곳에서.** 화면은 `/JGEngine/…` · `/JGGame/…` 토큰 경로만 쓰고, 디스크 경로로 바꾸는 일은 지금처럼 `HAssetPath` 가 맡는다.
- **필터는 두 단계.** 폴더 · 클래스로 먼저 고르고(GameFrameWork 함수), 그 결과에 이름 찾기 · 종류 칩을 건다(화면).
- **목록 그리기를 다시 쓸 수 있게.** 언리얼은 같은 목록 위젯을 고르기 창 · 열기/저장 창에서 다시 쓴다. 첫 판은 브라우저 하나지만 타일 그리기를 함수로 두어, 나중에 에셋 참조 칸의 고르기 창으로 쓸 수 있게 한다.
- **미뤄도 되는 것.** 썸네일 렌더 파이프라인(렌더러 등록 · 풀 · 시간 예산 · 저장), 컬렉션, 확장 보기, 여러 브라우저는 뼈대 흐름(트리 → 목록 → 열기)에 필요하지 않다.

## 알아 둘 것

- 에셋 DB 는 시작할 때 엔진 · 게임 Content 의 `.jgasset` 을 모두 비동기로 올린다(`GAssetDatabase::loadAssets`). 언리얼 에셋을 많이 가져오면 시작이 느려질 수 있다 — 첫 판은 그대로 두고 문제가 보이면 따로 일감.
- 파일 입출력이 좁은 문자 경로라 한글 폴더 · 파일 이름은 열리지 않는다(`DataTableAssets.h` 주석). 영문 이름만.
- 게임 Content 에는 `.jgasset` 보다 원본 파일(png · json · fbx)이 많다(ProjectAH Content 에 `.jgasset` 0개). 그래서 브라우저가 원본 파일도 "Source" 로 보여 주는 쪽을 택했다.
- 언리얼 에셋은 Epic 라이선스라 git 에 넣지 않는다(Engine-22).
