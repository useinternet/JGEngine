# 컨텐츠 브라우저 설계도 (Engine-24)

2026-10-24 Editor 세션 초안. 상위 일감 Engine-22 컨텐츠 브라우저. 바탕 조사: `Document/기록/Editor/Engine-23_언리얼컨텐츠브라우저_조사_2026-10-24.md`.
사용자 지시(프로젝트 총괄 전달): "컨텐츠 브라우저 만들기 ( 언리얼 레퍼런스 ) … 여기서 에셋 쓸만한거 가져오기 … 메시든 텍스쳐든 뭐든". 언리얼 에셋 가져오기는 Engine-26(GameFrameWork)이 따로 맡는다.
**이 설계도가 확인되기 전에는 코드를 고치지 않는다.**

## 1. 한 줄로

에디터에 **Content Browser 창**을 새로 만든다. 왼쪽 폴더 트리(`/JGEngine/` · `/JGGame/`)에서 폴더를 고르면, 가운데 타일에 메시 · 텍스처 · 데이터 테이블 · 원본 파일(.fbx · .png)이 보인다. 창에서 찾기 · 종류 거르기 · 가져오기 · 더블클릭 열기를 할 수 있다.
화면은 JGEditor 가, 폴더 읽기 · 가져오기 로직은 GameFrameWork 가 맡는다(런타임 로직과 에디터 UI 나눔). 약 2.5일 걸린다.

## 6. 알아 둘 것

- 에셋 DB 는 시작할 때 Content 의 `.jgasset` 을 모두 올린다. 언리얼 에셋을 많이 가져오면 에디터 시작이 느려지고 메모리를 더 쓴다. 첫 판은 그대로 두고, 문제가 보이면 필요할 때 올리기를 따로 일감으로 낸다.
- 파일 입출력이 좁은 문자 경로라 한글 폴더 · 파일 이름은 열리지 않는다(데이터 테이블과 같음). 영문 이름만 쓴다.
- 언리얼 에셋은 Epic 라이선스라 git 에 넣지 않는다(Engine-22). 시험 프로젝트 Content 에만 둔다.
