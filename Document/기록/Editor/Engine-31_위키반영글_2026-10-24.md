## 5. 2절 표 아래 — 쓰는 API 한 문단 더함

찾을 줄:

```
게임 에디터 모듈(`<프로젝트>Editor`)은 GUI의 `JGWidget`과 메뉴를 직접 사용해 게임 전용 창과 메뉴를 추가한다.
```

그 바로 위에 넣을 글(빈 줄 하나를 사이에 둔다):

```
`JGContentBrowser`는 폴더 목록과 원본 파일 가져오기를 [[05. 에셋|GameFrameWork 에셋]]의 `ListAssetFolder` · `ImportAssetFile`로 처리하고, 텍스처 그림과 메시 세부는 에셋 DB(`GAssetDatabase`)에 올라온 에셋에서 읽는다. 폴더 트리와 타일 더블클릭은 [[03. GUI|GUI]]의 `HGUI::TreeNode` · `TreePop` · `IsItemDoubleClicked`로 그리며, 데이터 테이블 타일을 더블클릭하면 `JGDataTableEditor::OpenTable`로 연다.
```
