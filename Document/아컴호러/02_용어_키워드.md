# 용어·키워드 대조표 (기본판)

작성 2026-09-29. 한국어 명칭은 한국어판 참조 안내서(arkham-cards-data `rules/ko`, 개정판 기준)와 ArkhamDB 한국어 카드 문구를 따릅니다.
등장 수는 기본판 카드 183종(플레이어 103 + 조우 80) 기준 **카드 종류 수**이고, 괄호 안은 실물 장수입니다. `01000`(무작위 기본 약점 자리표시자)과 `98004`(로랜드 재판)는 뺐고, 앞면·뒷면 문구를 모두 셉니다. P/E = 플레이어/조우.

## 요약

- 공식 한국어 표기와 흔히 쓰는 표기가 다른 용어가 많습니다: 은폐도 → **장막값**, 기술(판정) → **능력(테스트)**, 투입 → **소모**, 사퇴 → **후퇴**, 생성 → **출현**, 따로 빼두기 → **치워 두다**, 게임에서 제외 → **게임에서 제거하다**, 정신 외상 → **정신적 트라우마**, 서명 카드 → **전용 카드**, 클래스 → **역할군**, 막/아젠다 → **주요목적/주요사건**, 보급품 → **소모품**. 전체 목록은 §6 입니다(§N = 이 문서의 N절).
- 데이터 함정: 자유 격발 아이콘이 영문 문구에서는 `[fast]`, 한국어 문구에서는 `[free]` 입니다(같은 14종). 키워드 "신속(Fast)"과는 다른 것입니다.
- 한국어 한 단어가 두 개념을 가리키기도 합니다. "마법"은 슬롯(Arcane)이자 특성(Spell)이고, "소모"는 테스트에 카드를 넣는 것(commit)이지만 규칙 문장 일부에서는 행동을 쓰는 뜻으로도 나옵니다. 엔진 키는 영문 코드로 둡니다.
- 조우 카드 본문은 ArkhamDB에 한국어 번역이 없습니다. 그래서 조우 카드에만 나오는 키워드(보복·거대한·위험·출현 등)의 한국어 표기는 참조 안내서에서 가져왔습니다.
