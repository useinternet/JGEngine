# 06. 캠페인·시나리오: 광신도의 밤 (Night of the Zealot)

> 기본판(Core Set, 2016) 캠페인 3편 정리. 구조화 데이터는 `data/scenarios.json`(같은 내용). 카드·용어는 한국어판 명칭(첫 등장 시 영어 병기), 카드 원문·스토리는 옮기지 않고 효과만 요약. 작성 2026-09-29.

## 1. 요약

- 회합 → 한밤의 가면 → 지하 세계의 포식자를 고정 순서로 진행. 시나리오 분기는 없고, 결말은 다음 시나리오의 **셋업만** 바꾼다.
- 이월 요소: 캠페인 기록지(Campaign Log) 키 11종, XP(승점 더미 + 결말 보너스), 트라우마, 캠페인 카드 ‘리타 챈들러(Lita Chantler)’, 사망 조사자 교체, 3편 혼돈 주머니 `elder_thing` 추가.
- 연결 고리: 1편 결말 → 2편 시작 장소·구울 사제 투입 / 2편 추종자 결과 → 3편 초기 파멸·출현 적·시작 손 / 1편 리타 획득 → 3편 R3(희생) 선택지.
- 엔진 신규 요구: 별도 추종자 덱, 적 카드의 협상(승점 더미 직행), 뒷면이 적인 주요사건, 주요목적+주요사건 겸용 카드, 특성 기반 연결, 미공개 장소 무작위 배치.

미검증·주의:

- 결말 효과는 ArkhamCards 데이터 기준(현행 가이드 문구). 원본 2016 캠페인 가이드 인쇄본과 대조하지 못함 — 특히 회합 R3(대표 조사자 사망 시 선택 조사자가 리타 획득, XP 단계 없음)와 리타 획득자 표현(‘대표 조사자’).
- 캠페인 한국어명 ‘광신도의 밤’은 한국어판 참조 안내서(arkham-cards-data `rules/ko`)에서 확인. 기록 섹션 ‘캠페인 메모’는 출처 파일에 없는 임시 이름. 기호 혼돈 토큰 4종은 한국어판에 이름이 없어 id(영문)로 표기.
- 조우 카드에만 나오는 키워드의 한국어 표기(보복 Retaliate·거대한 Massive·급증 Surge·위험 Peril·목표 Objective, 미침 insane)는 한국어판 참조 안내서 기준. 카드 문구로는 대조하지 못함(ArkhamDB 한국어 조우 카드 텍스트가 영어). 먹잇감·사냥꾼·강제·폭로·협상·출현·후퇴·사망은 한국어 카드/.po에서도 확인.
- 장소 기호·연결: SCED GMNotes 전량 사용, 24장 공개 면 전부와 미공개 면 8장(01111·01112·01115·01125·01149·01150·01153·01156)을 이미지로 대조해 불일치 없음. 나머지 16장 미공개 면은 SCED만 사용(비숲 12장은 공개 면과 같은 기호·연결, 숲 4장은 대조한 01150b·01153b와 같은 공통 미공개 면).
- `slash` 기호는 실제로 사선 두 줄(//) 모양(SCED `SlantedEquals`). `moon`=SCED `Crescent`, `squiggle`=SCED `Tilde`, `t`=SCED `Tee`.
- 3편 ‘자정이 지났다’의 시작 손 2장 버림 시점(멀리건 전/후)은 텍스트상 불명 — 멀리건 후 적용을 권장(가정).
- ArkhamDB의 01121b(가면 쓴 사냥꾼)는 hidden 플래그지만 01121a 주요사건의 뒷면(같은 물리 카드, 둘 다 2/20) — 이미지로 확인.
