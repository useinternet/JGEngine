# 룰 요약 — 구현 명세 (기본판)

작성 2026-09-29. 범위: 아컴호러 카드 게임 오리지널 기본판(Core Set, 2016) — 조사자 5명, 캠페인 「광신도의 밤」 3편. 확장 규칙은 §16에 한 줄씩만 둡니다. 본문의 `§N` 은 이 문서의 N절입니다.
용어는 한국어판 참조 안내서(arkham-cards-data `rules/ko`) 표기를 따릅니다. 각 절 끝 `근거:` 에 참조 안내서 항목명(한국어 / English)을 적었습니다. 원문을 옮기지 않고 구현 관점으로 다시 썼습니다. 용어 대조는 `02_용어_키워드.md`, 시나리오별 세부는 `06_캠페인_시나리오.md` 를 봅니다.

## 0. 요약

- 협력 카드 게임입니다. 조사자마다 덱 1개, 시나리오 1편이 게임 1판, 캠페인은 시나리오의 연속입니다.
- 한 라운드는 신화 → 조사 → 적 → 정리 순서이고, 조사자는 차례마다 행동 3번을 씁니다. 판정은 "능력값 + 소모 아이콘 + 혼돈 토큰 ≥ 난이도" 하나뿐입니다.
- 단서를 모아 주요목적 덱을 넘기면 이기고, 파멸이 쌓여 주요사건 덱이 넘어가면 집니다. 어느 쪽이든 결말 지점 `(→결#)` 에 닿으면 시나리오가 끝납니다.
- 엔진의 뼈대는 고정 단계(사건 구조) + 그 사이의 플레이어 행동 기회 + "~할 때/~한 후" 격발 스택(LIFO) + 무작위 요소 3종(혼돈 주머니, 덱 섞기, 조우 덱)입니다.
- 기준 규칙: 한국어 참조 안내서(개정판 기준, 파일 최종 수정 2025-11-01), 영문 참조 안내서(2025-11-15). ArkhamDB 규칙 페이지(FAQ v2.5까지 표시)로 대조했습니다.

최상위 상태 기계:

```
Campaign
 ├─ CampaignSetup   기록지 초기화, 난이도 → 혼돈 주머니, 조사자 선택·덱 구성(§13)
 └─ loop Scenario
     ├─ Setup        게임 준비 13단계(§4)
     ├─ loop Round
     │   ├─ Mythos         1라운드 생략. 파멸 +1 → 한계값 검사 → 조우 카드 1장씩
     │   ├─ Investigation  조사자별 차례, 차례당 행동 3번
     │   ├─ Enemy          사냥꾼 이동 → 교전 중인 적 공격
     │   └─ Upkeep         행동 초기화 → 준비 → 1장·자원 1 → 손 8장
     │   (어느 시점이든 결말 지점 도달, 또는 전원 탈락 → 루프 탈출)
     ├─ ScenarioEnd  결말 해결, 승점 장소 정리
     └─ CampaignStep 기록 → 경험치·트라우마 → 카드 구입 → 다음 시나리오
```

## 1. 게임 개요

| 항목 | 규칙 |
|---|---|
| 인원 | 1–4인 협력. 전원이 함께 이기거나 진다. 기본판 1세트의 카드 풀은 2인분 |
| 조사자 | 플레이어 1명 = 조사자 1명 + 조사자 덱. 같은 조사자는 한 게임에 1명 |
| 게임 | 시나리오 1편. 캠페인 중 새 시나리오를 시작하면 새 게임 |
| 캠페인 | 시나리오 연속. 경험치·트라우마·기록이 이어진다. 시나리오에서 져도 캠페인은 계속 |
| 두 덱 | 주요목적 덱(조사자의 진척) 대 주요사건 덱(적대 세력의 진척). 결말 지점 표기는 한국어 `(→결#)`, 영문 `(→R#)` |

| 결과 | 조건 | 처리 |
|---|---|---|
| 완료 | 주요목적 쪽 지시로 결말 도달(독립 시나리오에서는 이것만 승리) | 캠페인 안내서의 같은 번호 결말 |
| 패배 | 주요사건 쪽 지시로 결말 도달 | 〃 |
| 결말 없음 | 조사자 전원 탈락(쓰러짐·후퇴) | 안내서의 "아무 결말에도 도달하지 못했다면" 항목 |
| 캠페인 패배 | 사망·미침으로 새 조사자를 골라야 하는데 남은 조사자가 없음 | 캠페인 종료 |

탈락은 두 가지입니다. **쓰러짐**은 피해 ≥ 체력 또는 공포 ≥ 정신력이고 캠페인이면 트라우마가 붙습니다. **후퇴**는 후퇴 지정 행동을 활성화한 것이고 쓰러진 것으로 보지 않습니다.

## 2. 카드 종류와 구성 요소

플레이어 카드(조사자 덱):

| 종류 | 한국어 | 엔진이 읽을 값 | 비고 |
|---|---|---|---|
| Investigator | 조사자 | 의지·지식·힘·민첩, 체력, 정신력, 기능, 고대 표식 효과, 뒷면(덱 크기·덱 구성 선택지·요구조건) | 인물 카드로 위치와 차례 종료를 표시 |
| Asset | 자산 | 비용, 레벨, 능력 아이콘, 슬롯, 체력·정신력(있으면), 사용(X), 고유 | 플레이 영역에 남는다 |
| Event | 이벤트 | 비용, 레벨, 능력 아이콘, 신속 여부, 플레이 지시 | 해결 후 버린다 |
| Skill | 능력 | 레벨, 능력 아이콘(만능 포함), 소모했을 때 효과 | 비용 없음. 플레이하지 않고 테스트에 소모 |
| Weakness | 약점 | 위 종류 또는 적·음모 종류 + 부가 종류 | 기본 약점(무작위 공용) / 전용 약점(조사자 지정) |

시나리오(조우) 카드:

| 종류 | 한국어 | 엔진이 읽을 값 |
|---|---|---|
| Scenario reference | 시나리오 참조 | 쉬움/보통 면, 어려움/전문가 면. `[skull]` `[cultist]` `[tablet]` `[elder_thing]` 효과 |
| Act | 주요목적 | 단계(1a…), 단서 한계값(보통 조사자당), `목표–` 지시문, 뒷면 진행 지시 |
| Agenda | 주요사건 | 단계, 파멸 한계값, 뒷면 진행 지시 |
| Location | 장소 | 미공개 면/공개 면, 장막값, 단서값(조사자당), 연결 기호, 승점 |
| Enemy | 적 | 전투값, 체력(조사자당일 수 있음), 회피값, 피해, 공포, 키워드, 출현·먹잇감, 승점 |
| Treachery | 음모 | 폭로 기능, 위협 영역·부착 뒤의 지속 기능, 승점 |
| Story asset | 이야기 자산 | 자산과 같음. 레벨 없음 + 조우 세트 기호(기본판: 리타 챈들러) |

| 토큰 | 용도 | 비고 |
|---|---|---|
| 단서 / 파멸 | 장소·조사자·주요목적의 단서, 주요사건·적·자산의 파멸 | 실물은 양면 토큰 하나 |
| 피해 / 공포 | 체력·정신력 손상 | 조사자·자산·적 |
| 자원 | 자원 저장소(비용 지불). 사용(X)의 이용물 표시에도 쓴다 | 이용물은 자원으로 치지 않는다 |
| 혼돈 토큰 | 혼돈 주머니에서 무작위 공개 | §7 |
| 수량 제한 | 없음. 모자라면 대체물 | 엔진은 정수 카운터 |

## 3. 영역(Zones)

| 영역 | Zone | 상태 | 정보 | 규칙 |
|---|---|---|---|---|
| 플레이 영역 | play area | 플레이 | 공개 | 조사자 카드, 자산. 조종자 기준 |
| 위협 영역 | threat area | 플레이 | 공개 | 교전 중인 적, 붙은 음모·약점. 그 조사자와 같은 장소로 본다 |
| 장소 | location | 플레이 | 미공개 면은 숨김 | 교전하지 않은 적, 부착물, 단서가 놓인다 |
| 현재 주요목적·주요사건 | current act/agenda | 플레이 | 공개 | 각 덱 맨 위 1장만 플레이 상태 |
| 자원 저장소 | resource pool | 플레이 | 공개 | 플레이 중 카드 위 토큰도 플레이 상태 |
| 손 | hand | 비플레이 | 본인만 | 정리 단계에 8장 제한 |
| 조사자 덱 | investigator deck | 비플레이 | 숨김, 순서 고정 | 효과 없이는 순서를 바꾸지 않는다 |
| 조우 덱 | encounter deck | 비플레이 | 숨김 | 비면 버린 조우 카드 더미를 섞어 다시 만든다 |
| 주요목적·주요사건 덱 | act/agenda deck | 비플레이 | 순서대로 | 1a가 맨 위 |
| 버린 카드 더미 | discard pile | 비플레이 | 공개 | 조사자별 1개 + 버린 조우 카드 더미 1개. 순서 변경 금지 |
| 승점 더미 | victory display | 비플레이 | 공개 | 전원 공유. 끝나면 경험치 |
| 치워 둔 카드 | set aside | 비플레이 | — | 지시가 부를 때까지 게임과 무관 |
| 게임에서 제거 | removed from game | 비플레이 | — | 기간이 없으면 게임 끝까지 |
| (림보) | limbo | 어느 쪽도 아님 | 공개 | 해결 중인 이벤트·음모, 테스트에 소모된 능력 카드 |

- 소유자는 게임 시작 때 그 카드가 들어 있던 덱(영역)의 주인입니다. 조우 카드는 조우 덱(시나리오)이 소유합니다.
- 카드는 소유자 조종으로 플레이에 들어옵니다. 남의 비플레이 영역으로 가야 하면 실물만 소유자의 같은 영역에 둡니다.
- 조우 종류 약점은 덱 안에서는 플레이어 카드, 해결을 시작한 뒤부터 조우 카드(아무도 조종하지 않음)입니다. 플레이어 종류 약점은 보유자가 조종합니다.
- 플레이 영역에서 나가면 동시에 토큰 반납, 부착물 버림, 그 카드에 걸린 지속·지연 효과 만료가 일어납니다. 플레이어 카드 위의 단서는 그 장소로 갑니다.

- 멀리건: 원하는 장수를 골라 치워 두고 그만큼 새로 뽑은 뒤, 치워 둔 카드를 덱에 섞습니다. 1회뿐입니다.
- 8단계에서 약점을 뽑으면 해결하지 않고 치워 두고 1장 더 뽑습니다. 8단계가 끝나면 치워 둔 약점을 각자 덱에 섞습니다.
- 준비 중에는 플레이어의 행동 기회가 없습니다. 격발 조건이 명시적으로 충족된 카드만 쓸 수 있습니다. 급증은 준비 중에도 해결하고, 준비 중 덱 찾기로는 "찾을 때" 격발이 일어나지 않습니다.

⚡ 는 플레이어의 행동 기회(player window)입니다. `[free]` 기능, 기간이 적힌 신속 이벤트, 자기 차례의 신속 자산을 여기서 씁니다. 능력 테스트 안에도 1단계 뒤와 2단계 뒤 두 곳이 있습니다(§7). `[reaction]` 과 시점이 적힌 신속 이벤트는 창과 상관없이 격발 조건에서 씁니다.

조우 카드 1장 뽑기(신화 1.4와 카드 효과로 뽑을 때 공통):
1. 조우 덱 맨 위 1장을 뽑는다(비어 있으면 버린 조우 카드 더미를 섞어 덱으로).
2. 위험 키워드 확인. 있으면 해결이 끝날 때까지 다른 플레이어의 개입을 막는다.
3. 폭로 기능 해결.
4. 적이면 출현(§8). 음모면 달리 지시가 없는 한 버린 조우 카드 더미로(승점이 있으면 승점 더미로).
5. 급증이면 1부터 다시.

## 6. 행동

차례마다 행동 3번(순서 자유, 같은 행동 반복 가능)에 카드가 주는 추가 행동이 더해집니다. 행동의 비용을 먼저 다 내고 결과를 해결합니다.

| 행동 | 한국어 | 대상 | 효과 | 틈새 공격 |
|---|---|---|---|---|
| Investigate | 조사 | 내 장소 | 지식 vs 장막값. 성공하면 단서 1 발견 | 유발 |
| Move | 이동 | 이어진 장소 | 인물 카드 이동. 처음 들어간 미공개 장소는 공개하고 단서값만큼 단서를 놓는다(장소 카드가 플레이에서 나갔다 다시 들어와 공개되면 단서값까지 다시 채움, 영문 FAQ 1.39) | 유발 |
| Draw | 카드 뽑기 | — | 1장 | 유발 |
| Resource | 자원 | — | 자원 1 | 유발 |
| Play | 플레이 | 손의 자산·이벤트(신속 제외) | 자원 비용을 내고 플레이 | 유발 |
| Activate | 활성화 | `[action]` 기능 | `[action]` 개수만큼 행동. 대상: 내가 조종하는 카드(조사자 카드 포함), 내 장소의 시나리오 카드(장소 자체, 그곳의 조우 카드, 그곳 조사자들의 위협 영역 카드), 현재 주요목적·주요사건 | 유발(아래 예외) |
| Fight | 전투 | 내 장소의 적 누구든 | 힘 vs 전투값. 성공하면 피해 1(무기로 가감). 실패했는데 그 적이 다른 조사자 1명과 교전 중이면 그 조사자가 피해를 받는다 | 없음 |
| Engage | 교전 | 내 장소의 적(소진된 적, 냉담한 적, 남과 교전 중인 적) | 내 위협 영역으로 가져온다. 이미 나와 교전 중인 적은 불가 | 유발 |
| Evade | 회피 | 나와 교전 중인 적 | 민첩 vs 회피값. 성공하면 적을 소진하고 교전 해제(적을 장소로) | 없음 |
| Resign | 후퇴 | 후퇴 지정 행동이 있는 카드 | 활성화로 쓴다. 탈락하지만 쓰러짐은 아님 | 없음 |
| Parley | 협상 | 협상 지정 행동이 있는 카드 | 활성화로 쓴다. 효과는 카드마다 | 없음 |

- 기본 행동은 뽑기·자원·이동·조사·전투·교전·회피입니다. 활성화·플레이·후퇴·협상은 기본 행동이 아닙니다(영문 FAQ 1.30).
- 지정 행동(굵은 **전투.** **조사.** **회피.** 등): 그 기능을 쓰면 해당 행동을 한 것이고 방식만 카드대로 바뀝니다. 그래서 전투·회피 지정 행동은 틈새 공격을 유발하지 않습니다.
- 추가 행동은 조건에 맞는 첫 행동에 자동으로 먼저 쓰입니다. 행동을 잃으면 기본 3번에서 먼저 잃습니다. 차례 밖에서는 카드가 허락하지 않는 한 행동을 쓸 수 없습니다.
- 행동 비용이 늘어나는 예: 공포에 얼어붙다(라운드 첫 이동·전투·회피에 +1), `[action][action]` 기본 약점 3종(행동 2번).

틈새 공격(Attack of Opportunity):
- 조건: 준비된 적과 교전 중인 조사자가 행동을 써서 전투·회피·협상·후퇴가 아닌 행동을 할 때, 교전 중인 준비된 적마다 1번.
- 시점: 그 행동의 비용을 다 낸 직후, 효과 적용 전입니다. 순서는 그 조사자가 정하고, 적은 소진되지 않으며, 카드 효과상 적의 공격으로 칩니다.
- 행동 여러 번짜리 기능도 적마다 1번입니다. 신속 카드, `[free]`, `[reaction]` 은 행동을 쓰지 않으므로 유발하지 않습니다. 거대한 적은 유발한 조사자만 공격합니다.

근거: 행동 / Action, 활성화 행동 / Activate Action, 조사·이동·카드 뽑기·자원·플레이·전투·교전 행동 / Investigate·Move·Draw·Resource·Play·Fight·Engage Action, 회피, 회피 행동 / Evade, 후퇴 / Resign, 협상 / Parley, 지정 행동 / Action Designators, 틈새 공격(+보충 1.1) / Attack of Opportunity, 추가 행동 얻기/잃기(보충 1.10), Basic Action Types(영문 FAQ 1.30)

## 7. 능력 테스트

| 단계 | 처리 | 창 |
|---|---|---|
| 1 | 테스트 종류(의지·지식·힘·민첩) 결정, 테스트 시작 | 후 ⚡ |
| 2 | 카드 소모. 테스트하는 조사자는 손에서 적합한 아이콘이 있는 카드를 원하는 만큼, 같은 장소의 다른 조사자는 각자 1장까지. 적합 = 테스트 능력과 같은 아이콘 또는 만능. 아이콘 1개당 +1, 비용 없음 | 후 ⚡ |
| 3 | 혼돈 토큰 1개를 무작위 공개 | |
| 4 | 기호 효과: 기호 4종은 시나리오 참조 카드(고른 난이도 면), `[elder_sign]` 은 테스트하는 조사자의 카드, `[auto_fail]` 은 자동 실패 | |
| 5 | 보정된 능력값 = 기본 능력 + 적합 아이콘 수 + 토큰 수치 + 활성 보정 | |
| 6 | 성공/실패 결정: 능력값 ≥ 난이도면 성공. 성공·실패·차이를 조건으로 하는 `[reaction]`·강제 기능은 여기서 격발 | |
| 7 | 결과 적용: 테스트 자체의 결과(단서, 피해, 회피)와 "성공하면" 효과를 하나씩. 여러 개면 테스트한 조사자가 순서를 정한다 | |
| 8 | 종료: 소모한 카드를 버리고 공개한 토큰을 주머니로 | |

- 난이도: 전투 = 적 전투값, 조사 = 장소 장막값, 회피 = 적 회피값, 카드 = 능력 뒤 괄호 값(예: `[intellect] (2)`). 다른 값에 연동된 난이도는 계속 갱신되지만, 판정에 쓴 값은 그 순간 값으로 고정합니다(영문 FAQ 1.38).
- 자동 실패는 능력값 0, 자동 성공은 난이도 0으로 6단계에서 봅니다. 3단계 전에 결과가 정해지면 3·4단계를 건너뜁니다(소모와 능력값 계산은 그대로). "자동으로 회피" 효과는 테스트 자체가 없고 성공으로 치지 않습니다.
- 보정: 인쇄된 기본값에서 모든 보정을 매번 다시 계산합니다. 더하기·빼기를 먼저, 곱하기·나누기를 나중에 하고 분수는 올림합니다. 결과가 음수면 0으로 취급하지만 보정치는 그대로 누적됩니다(4 − 8 + 2 = −2 → 여전히 0).
- 차이: "N 이상 차이로 성공" = 능력값 − 난이도 ≥ N, "모자란 차이마다" = 난이도 − 능력값. 6단계 값을 7단계까지 씁니다(카드 문구 기준 해석).
- 소모 제한: "능력 테스트당 최대 1장 소모"는 명칭 기준으로 전원 합계입니다. 기회주의자는 자기가 하는 테스트에만 소모합니다. 위험 조우를 해결하는 동안은 다른 조사자가 소모할 수 없습니다.
- 테스트 도중 다른 테스트가 시작되려 하면, 지금 테스트(행동의 일부면 그 행동)가 끝난 뒤에 시작합니다.
- 토큰 여러 개를 "해결"하면(어려움 `[cultist]` 의 "1개 더 공개") 해결한 토큰의 수치와 효과를 모두 적용합니다. 여러 개를 공개하고 1개만 해결하는 효과(기괴한 석상)는 나머지를 무시하고, 웬디 애덤스처럼 취소하고 다시 공개하는 효과도 있습니다.

| 혼돈 토큰 | 처리 |
|---|---|
| 숫자(+1, 0, −1 … −8) | 능력값에 더한다 |
| `[skull]` `[cultist]` `[tablet]` `[elder_thing]` | 현재 시나리오 참조 카드의 해당 줄(수치 + 추가 효과) |
| `[auto_fail]` | 자동 실패 |
| `[elder_sign]` | 조사자 카드의 고대 표식 효과 |

주머니 구성은 캠페인 안내서가 난이도별로 정합니다(06 문서).

## 8. 적

| 주제 | 규칙 |
|---|---|
| 출현 | 뽑은 적은 출현 지시문이 있으면 그 장소, 없으면 뽑은 조사자와 교전한 채 그 위협 영역에. 지시문은 어떤 방식으로 들어오든 적용한다. 맞는 장소가 없으면 출현하지 않고 버린다. 후보가 여럿이면 출현시키는 조사자가 고른다. 카드 효과가 장소를 지정하면 그것이 지시문을 대신한다 |
| 출현 후 교전 | 장소에 출현하면 바로 교전 규칙을 적용한다(냉담한 적 제외). 먹잇감은 출현 장소를 바꾸지 않는다. 예외 카드: 가면 쓴 사냥꾼(먹잇감과 교전한 채 출현) |
| 교전 | 준비 상태 + 교전 안 함 + 조사자와 같은 장소 → 즉시 교전(위협 영역으로). 출현, 적 이동, 조사자 이동, 소진된 적이 준비될 때 검사한다. 후보가 여럿이면 먹잇감, 그래도 같으면 대표 조사자. 교전 수 제한 없음 |
| 교전 유지 | 위협 영역의 적은 그 조사자와 같은 장소로 보고 함께 이동한다. 내가 교전한 것과 적이 나와 교전한 것은 같은 사건 |
| 소진된 적 | 교전하지 않은 소진 적은 새로 교전하지 않는다. 소진 적은 적 단계 공격도 틈새 공격도 하지 않는다. 준비되는 순간 교전을 검사한다 |
| 사냥꾼 (3.2) | 준비 + 교전 안 한 사냥꾼 적은 가장 가까운 조사자 쪽으로 최단 경로를 따라 이어진 장소 1칸 이동. 조사자가 있는 장소에 있으면 이동하지 않는다. 가장 가까운 조사자가 여럿이면 먹잇감, 그다음 대표 조사자. 경로가 카드 효과로 막히면 이동하지 않는다. "가장 가까운"은 막힌 연결도 거리로 센다 |
| 먹잇감 | 이동·교전 후보를 고르는 기준. "오직 ~만"이면 그 조사자만 있는 것처럼 행동한다(다른 조사자가 교전 행동으로 가져갈 수는 있다) |
| 적 공격 (3.3) | 플레이어 순서대로, 조사자마다 교전 중인 준비된 적 전부. 피해와 공포를 동시에 준다. 공격과 그로 인한 격발이 끝나면 그 적을 소진한다. 공격 순서는 공격받는 조사자가 정한다 |
| 보복 | 준비된 보복 적을 공격하다 테스트에 실패하면, 결과 적용 뒤 그 적이 공격자를 공격한다. 소진 안 함, 교전 여부 무관 |
| 거대한 | 준비 상태면 같은 장소 조사자 전원과 교전(위협 영역에 두지 않고 따라가지 않음). 적 단계에는 대표 조사자가 정한 순서로 전원을 한 명씩 공격하고 마지막 공격 뒤 소진. 틈새 공격은 유발자만. 전투 실패 시 다른 조사자에게 피해 없음 |
| 냉담한 | 기본판 카드 없음. 교전하지 않은 채 출현하고 자동 교전하지 않으며, 교전 전에는 공격할 수 없다 |
| 회피됨 | 준비 상태였으면 소진, 그리고 교전 해제(그 장소에 놓는다) |
| 쓰러뜨림 | 피해 ≥ 체력. 승점이 있으면 승점 더미, 약점 적이면 소유자의 버린 카드 더미, 그 밖에는 버린 조우 카드 더미 |

## 9. 피해·공포와 패배

| 단계 | 처리 |
|---|---|
| 1 할당 | 받을 양을 정한다. 조사자는 자신이 조종하는 자산 중 체력(피해)·정신력(공포)이 있는 자산에 나눠 줄 수 있고, 자산마다 쓰러지는 데 필요한 양까지만. 나머지는 조사자 |
| (사이) | 방어·감소·재할당 효과 |
| 2 적용 | 할당한 것을 동시에 올린다. 하나도 안 올라가면 "피해를 준 것"이 아니다 |
| 3 판정 | 조사자: 피해 ≥ 체력 또는 공포 ≥ 정신력이면 쓰러짐. 자산: 같은 조건이면 소유자의 버린 카드 더미로. 적: §8 |

- "피해를 X 받습니다"는 내 조사자에게 X를 준다는 뜻이라 자산에 할당할 수 있습니다. **직접적인** 피해·공포는 지정한 카드에만 놓습니다.
- 체력·정신력 값이 없는 자산은 0이 아니라 "없음"이어서 할당 대상이 아닙니다. 남은 체력 = 기본 체력 − 피해 ± 보정입니다.
- 비용으로 받은 피해를 자산에 돌려도 비용은 낸 것입니다. "당신에게 피해를 준 후" 격발은 내 자산이 받은 경우도 포함합니다.
- 회복은 지정한 양만큼, 있는 만큼만 제거합니다.
- 빈 조사자 덱에서 뽑아야 하면 버린 카드 더미를 섞어 덱으로 만들어 뽑고, 뽑기를 마친 뒤 공포 1을 받습니다.

| 쓰러진 원인(캠페인) | 결과 |
|---|---|
| 피해 ≥ 체력 | 육체적 트라우마 1. 이후 시나리오마다 트라우마당 피해 1을 안고 시작. 누적 ≥ 인쇄 체력이면 **사망** |
| 공포 ≥ 정신력 | 정신적 트라우마 1. 이후 시나리오마다 공포 1. 누적 ≥ 인쇄 정신력이면 **미침** |
| 둘 다 동시에 | 어느 트라우마를 받을지 본인이 고른다 |
| 카드 기능 | 그 카드의 지시대로. 탈락 처리는 같다 |
| 독립 시나리오 | 게임 중 쓰러짐에는 트라우마 없음(결말의 트라우마는 적용) |

탈락 처리(쓰러짐·후퇴 공통, 순서대로):
1. 탈락한 조사자에게는 게임이 끝난 것으로 보고, 그가 소유한 플레이 중 약점의 "게임이 끝날 때" 기능을 격발한 뒤 그 약점들을 게임에서 제거한다.
2. 그가 조종하는 플레이 중 카드와 손·덱·버린 카드 더미를 전부 게임에서 제거한다. 그가 소유하지만 남이 조종하는 카드는 남기고, 나중에 나가면 제거한다.
3. 가진 단서는 마지막 장소에, 자원은 토큰 저장소로.
4. 교전 중이던 적은 그 장소에 교전하지 않은 상태로 둔다(소진·피해 등은 유지).
5. 위협 영역의 나머지 카드는 각자의 버린 카드 더미로.
6. 대표 조사자였다면 남은 사람이 새로 정한다.
7. 남은 조사자가 없으면 시나리오 종료("결말 없음").

탈락한 조사자도 조사자당 값 계산에는 계속 들어갑니다.

## 10. 능력과 타이밍

| 종류 | 표기 | 발동 | 핵심 |
|---|---|---|---|
| 상시 | 서식 없음 | 플레이 중 항상 | 개시 시점 없음. "~동안" 같은 조건형 포함 |
| 강제 | **강제 –** | 시점이 오면 자동, 의무 | 게임 상태를 바꿀 수 없으면 개시하지 않는다. 같은 시점의 반응보다 먼저 전부 해결 |
| 폭로 | **폭로 –** | 조우 카드·약점을 뽑을 때 | 플레이에 들어가거나 버려지기 전에 해결 |
| 자유 격발 | `[free]` | 아무 플레이어의 행동 기회 | 행동 비용 없음 |
| 반응 격발 | `[reaction]` | 격발 조건이 생길 때마다 | 조건 1회에 기능당 1번. 다른 반응을 막지 않는다 |
| 행동 격발 | `[action]` | 자기 차례의 활성화 행동 | `[action]` 1개 = 행동 1번 |
| 키워드 | 신속, 사냥꾼 등 | 키워드별 | "해도 된다" 키워드만 선택형. 같은 키워드가 겹쳐도 1개 |
| 적 지시문 | **출현 –**, **먹잇감 –** | 적이 들어올 때, 고를 때 | §8 |

- 격발 기능을 쓸 수 있는 곳: 내가 조종하는 플레이 중 카드(조사자 카드 포함), 내 장소의 시나리오 카드(장소 자체, 그곳의 조우 카드, 그곳 조사자들의 위협 영역 조우 카드), 현재 주요목적·주요사건, 사용을 명시적으로 허락한 카드.
- 신속: 이벤트는 플레이 지시에 적힌 시점(격발 조건처럼)이나 기간 안의 창에서, 자산은 자기 차례의 창에서 플레이합니다. 플레이 행동이 아니므로 틈새 공격이 없습니다.
- 개시할 수 있는 조건: 효과가 게임 상태를 바꿀 가능성 + 비용(보정 반영)을 다 낼 가능성. 대상이 필요한데 유효 대상이 없으면 개시할 수 없습니다. 개시한 뒤에는 "해도 된다"가 아닌 부분을 할 수 있는 만큼 해결합니다.

개시 순서(카드 플레이·격발 기능 공통):

```
선언 → [검사] 플레이 제한, 상태 변화 가능성 → [검사] 비용 확정, 지불 가능성
 → 1 비용 보정 적용 → 2 비용 지불(동시에; 못 내면 아무것도 내지 않고 취소)
 → (틈새 공격 해결) → 3 플레이 시작/효과 개시(여기서 취소될 수 있음)
 → 4 효과 해결 완료. 카드는 플레이된 것(자산은 플레이 영역, 이벤트는 버린 카드 더미)
```

- 비용은 그 카드·기능의 조종자만, 자기 게임 요소로만 냅니다. 조사자들이 "모아서" 내는 비용은 해당 조사자들이 나눠 냅니다. 도중에 그 카드가 플레이에서 나가도 순서는 끝까지 갑니다.
- 추가 비용은 효과를 해결하는 순간에 내고, 못 내면 그 부분만 실패합니다. 강제·의무 지시로 해결할 때는 추가 비용을 내지 않습니다.

| 표기 | 영문 | 해결 위치 |
|---|---|---|
| ~하려 할 때 | would | 같은 조건의 "~할 때"보다 먼저. 대체 효과가 조건을 바꾸면 원래 조건을 보는 다른 기능은 쓸 수 없다 |
| ~할 때 | when | 조건이 개시된 직후, 결과 적용 전(끼어들기) |
| ~에 / ~하면 | at / if | "~할 때"와 "~한 후" 사이 |
| ~한 후 | after | 조건이 완전히 끝난 직후 |
| 그런 다음 | then | 앞부분을 완전히 해결해야 뒷부분을 해결. 뒷부분은 앞부분이 일으킨 "~한 후" 격발보다 먼저 |

- 중간에 낀 과정: 조건마다 (~할 때 → 해결 → ~한 후)를 돌립니다. 그 안에서 반응·강제가 새 조건을 만들면 새 과정을 끝까지 돌리고 돌아옵니다. LIFO 스택이고 깊이 제한은 없습니다.
- 한 효과의 모든 부분은 그 효과가 일으킨 "~한 후" 격발보다 먼저 해결합니다.
- 대신(대체 효과): 같은 조건에 대체 효과가 여럿이면 가장 나중에 개시한 것을 적용합니다.
- "할 수 없다"는 절대적이어서 다른 기능이 뒤집지 못합니다.
- 취소: 기능은 개시된 것으로 보고 비용도 돌려받지 않습니다. 취소된 이벤트는 플레이한 것, 음모는 뽑은 것으로 보고 각각 버립니다.
- 동시 해결: 여러 플레이어가 각자 골라야 하면 플레이어 순서대로 고르고 동시에 적용합니다. 동시에 걸린 강제 기능과 충돌하는 상시 효과의 순서는 대표 조사자가 정합니다.
- 우선순위: 카드 문구 > 참조 안내서 > 규칙서(항상 우선하는 규칙). 두 카드가 정면으로 충돌하면 조우 카드가 이기고, 같은 쪽끼리면 대표 조사자가 정합니다(부차적인 충돌 규칙). 규칙에 답이 없으면 조사자에게 가장 불리하게(무자비한 규칙). 유효한 선택지 가운데 고르는 일은 무자비한 규칙이 아니라 대표 조사자의 몫입니다.

| 한정·최대 | 범위 | 기본판 예 |
|---|---|---|
| 기간당 X번 한정 | 기능 인스턴스별, 플레이어별. 나갔다 다시 들어오면 새 인스턴스 | 라운드당 1번(로랜드), 차례당 1번(스키즈, 당신의 집), 단계당 1번(애그니스), 테스트/기능당 1번(웬디), 라운드당 2번(병원 빚), 게임당 1번(장소 5곳) |

## 11. 주요목적·주요사건 진행

| 항목 | 주요목적(Act) | 주요사건(Agenda) |
|---|---|---|
| 조건 | 조사자들이 단서 한계값만큼 단서를 모아 소비 | 플레이 중 파멸 총합(주요사건 + 다른 모든 카드) ≥ 파멸 한계값 |
| 시점 | 아무 조사자의 차례 중 `[free]` 플레이어 기능. 누구든 몇 개씩이든 분담 | 신화 1.3에서만. 예외는 "이 효과는 현재 주요사건을 진행시킬 수 있습니다" 문구가 있는 카드(어두운 기억, 고대의 악, 힘의 거래) |
| `목표–` | 조건을 대체하거나 추가(라운드 끝에 복도의 조사자들이 소비, 적 처치, 장소 진입 등) | 조건 대체·추가 |
| 값 | 대부분 조사자당 | 기본판은 고정값 |

진행 절차(공통):
1. 진행하는 카드 위 토큰을 제거한다. 주요사건이면 플레이 중 모든 카드의 파멸을 제거한다.
2. 뒤집어 b면 지시를 따른다. b면이 조우 카드면 그 종류를 뽑은 것처럼 해결한다(주요사건 1b = 적 '가면 쓴 사냥꾼').
3. 달리 지정하지 않으면 덱의 다음 카드가 현재 카드가 되고, 진행한 카드는 동시에 게임에서 제거된다.

- b면이나 다른 카드의 `(→결#)` 에 닿으면 즉시 시나리오가 끝나고 결말로 갑니다.
- 한 카드가 현재 주요목적이자 현재 주요사건이 되는 경우가 있습니다(지하 세계의 포식자 3b). 엔진의 두 슬롯이 같은 인스턴스를 가리킬 수 있어야 합니다.
- 파멸은 주요사건 밖의 카드(사교도 시종, 교단의 마법사, 플레이어 자산 비술 입문자)에도 쌓이고 한계값에 합산됩니다.

## 15. 엔진 구현 체크리스트

1. 결정론: 상태 + 명령 + 시드 RNG. 무작위 지점은 혼돈 토큰 공개, 덱 섞기(조사자 덱, 조우 덱, 멀리건·찾기 후), 무작위 기본 약점, 무작위 손패 버리기(주요사건 1b 선택지, 이스인 관찰자), 대표 조사자 무작위 결정입니다. 스트림을 나눠 기록하면 재현이 쉽습니다.
2. 사건 구조를 상태 기계로 둡니다: Campaign → Scenario(준비 13단계) → Round(단계·세부 단계) → Turn → Action → 개시 순서 → 능력 테스트 1–8단계. 단계마다 시작·끝 이벤트를 냅니다.
3. 격발 파이프라인: 모든 게임 사건에 would → when(강제 먼저, 그다음 반응 기회) → 해결 → at/if → after(강제 먼저, 반응) 훅을 둡니다. 새 사건은 스택에 올려 LIFO로 처리합니다.
4. 플레이어 행동 기회를 명시적 결정 지점으로 둡니다(§5 표의 창 + 능력 테스트 1·2단계 뒤). 창 안에서 누가 먼저 쓰는지는 규칙에 없으므로 모두 "통과"할 때까지 도는 프로토콜을 정해야 합니다.
5. 플레이어 입력이 필요한 곳: 멀리건, 차례 순서, 행동 선택, 소모 카드, 피해·공포 할당, 틈새 공격·적 공격 순서, 출현 장소 후보, "하나를 선택" 효과, 손패 정리, 슬롯 초과 버림, 트라우마 종류, 반응·자유 기능 사용 여부, 대상, X 값. 대표 조사자 결정: 사냥꾼 경로와 먹잇감 동률, 동시 강제 기능 순서, 동시에 버리는 조우 카드 순서.
6. 합법성 검사기: 게임 상태 변화 가능성, 비용 지불 가능성(보정 반영), 유효 대상, "할 수 없다" 우선. 할 수 있는 행동이 없으면 2.2.2로 넘깁니다.
7. 보정 계산기: 인쇄값(조사자당 곱셈 포함) → 가감 → 배수 → 올림 → 0 하한. 인쇄된 특징과 획득한 특징, 백지화를 구분합니다.
8. 한정 카운터: 기능 인스턴스 × 기간(테스트·차례·단계·라운드·게임), 그룹 한정, 명칭별 최대. 플레이에서 나가면 인스턴스를 새로 만듭니다.
9. 지속·지연 효과 레지스트리: 기간, 만든 순간의 대상 스냅샷, "~끝에" 격발보다 먼저 만료.
10. 영역·인스턴스 모델: 카드 정의(불변, 03 문서)와 인스턴스{소유자, 조종자, 영역, 소진, 면(공개·미공개, a/b), 토큰 맵, 부착}를 나눕니다. 림보를 별도 영역으로 둡니다.
11. 장소 그래프: 연결 기호로 이동, BFS 최단 거리(가장 가까운), 이동 차단 효과, 처음 공개 시 조사자당 단서 배치.
12. 적 규칙: 교전 검사(출현·이동·준비 직후), 사냥꾼 이동, 먹잇감 평가(최고 힘, 최저 남은 체력·정신력, 최다 단서, 최소 손패, 최저 민첩·힘, 보유자만), 보복, 거대한, 공격 후 소진.
13. 피해 파이프라인: 할당(자산 흡수 선택) → 방어·감소 → 동시 적용 → 쓰러짐 판정 → 탈락 7단계.
14. 조우 뽑기 파이프라인: 위험(다른 플레이어 입력 잠금), 폭로, 출현·버림·승점 더미, 급증 반복, 빈 덱 재구성. 약점 뽑기는 조우 종류와 플레이어 종류로 분기합니다.
15. 주요목적·주요사건: 모든 카드의 파멸 합산, 1.3에서만 진행(예외 플래그), 단서 공동 소비, `목표–` 오버라이드, b면 해결(조우 카드일 수 있음), 한 카드가 두 슬롯을 차지하는 경우.
16. 숨은 정보: 손, 덱 순서, 조우 덱, 치워 둔 카드, 미공개 장소 뒷면. 혼돈 주머니는 구성은 공개, 뽑기는 무작위. 표시 계층에는 권한별 뷰만 넘깁니다.
17. 캠페인 저장: 기록지(문구를 문자열 키로 그대로), 조사자별 경험치·트라우마·얻은 카드·사망/미침, 혼돈 주머니 구성, 결말 이력.
18. 카드 효과는 카드 코드별로 구현합니다(`text` 는 표시용). 이 문서의 키워드·지시문을 공용 컴포넌트로 먼저 만들면 기본판 효과 대부분을 조합으로 덮을 수 있습니다.
