# 카드 데이터 명세 — `data/cards.json`

작성 2026-09-29. 대상: 아컴호러 카드 게임 기본판(Core Set, 2016) 183종. 용어는 `02_용어_키워드.md` 의 공식 한국어 표기를 따릅니다.

## 요약

- 기본판 카드 183종(플레이어 103, 조우 80)을 한/영 병기 JSON 한 파일로 정리했습니다. 원본은 ArkhamDB 공개 API이고(`data/raw/`), `tools/build_cards.pl` 이 생성합니다.
- `text` 는 사람이 읽는 문자열(마크업 포함)일 뿐 효과를 기계가 읽을 수 있는 형태가 아닙니다. 엔진은 카드 코드별로 효과를 구현하고 `text` 는 표시용으로만 씁니다. `keywords`, `ability_icons`, `uses`, `spawn`, `prey` 는 영문 텍스트(앞뒷면)에서 뽑은 보조 필드입니다.
- 한국어가 없는 필드는 `ko: null` 입니다(조우 카드 본문 66장, 배경 글 다수). 표시할 때 `en` 으로 대체합니다.

## 생성 흐름

```
ArkhamDB API 전체 덤프(en, ko) ──extract_raw.pl──▶ data/raw/arkhamdb_{core,rcore}_{en,ko}.json
data/raw/* + data/scenarios.json ──build_cards.pl──▶ data/cards.json   (장소 기호·연결, 세트별 사용 시나리오 병합)
data/cards.json ──gen_lists.pl──▶ 04_플레이어_카드.md, 05_조우_카드.md
```

전체 재생성은 `bash tools/update.sh` 입니다(`--images` 를 붙이면 빠진 이미지도 받습니다). `python` 은 이 PC에서 동작하지 않아 perl(JSON::PP)로 작성했습니다.

## 공통 필드

| 필드 | 타입 | 설명 |
|---|---|---|
| `code` | string | ArkhamDB 카드 코드 = 팩 번호 2자리 + 카드 번호 3자리. 한 장의 앞뒤가 서로 다른 카드이면 `a`/`b` 를 붙인다(`01121a`, `01121b`) |
| `position` | int | 팩 안 수집 번호 |
| `name`, `subname` | {ko, en} | 이름, 부제(조사자와 일부 고유 카드) |
| `type` | enum | `investigator` `asset` `event` `skill` `treachery` `enemy` `location` `act` `agenda` `scenario` |
| `type_name` | {ko, en} | 조사자 / 자산 / 이벤트 / 능력 / 음모 / 적 / 장소 / 주요목적 / 주요사건 / 시나리오 |
| `subtype` | enum? | `weakness`(전용 약점), `basicweakness`(기본 약점) |
| `faction` | enum | 역할군. `guardian` `seeker` `rogue` `mystic` `survivor` `neutral`, 조우 카드는 `mythos` |
| `deck` | enum | `player` / `encounter` |
| `quantity` | {core, revised_core} | 기본판 / 개정판(2020) 매수. 조우 카드는 두 판이 같다 |
| `unique` | bool | 고유(✷). 같은 명칭은 플레이 중 1장만 |
| `traits` | {ko: [], en: []} | 특성 |
| `keywords` | string[] | 텍스트와 수치 필드에서 뽑은 키워드(아래 표) |
| `ability_icons` | {action, reaction, free} | 앞뒷면 텍스트 안 격발 아이콘 개수 |
| `text`, `flavor` | {ko, en} | 앞면 본문(마크업 포함), 배경 글 |
| `back` | {name, text, flavor} | 뒷면. 조사자 = 덱 구성 규칙, 주요목적·주요사건 = 진행 효과, 장소 = 반대쪽 면, 시나리오 = 어려움/전문가 토큰 효과 |
| `double_sided` | bool | 양면 카드 |
| `linked_to` | string? | 앞뒷면이 서로 다른 카드로 등록된 경우의 다른 면 코드 |
| `hidden` | bool? | ArkhamDB 목록에서 숨긴 카드(`01121b`) |
| `victory` | int? | 승점 X. 적은 쓰러뜨리면, 장소는 시나리오가 끝날 때 공개 상태이고 단서가 없으면 승점 더미로 간다 |
| `errata_date` | string? | 정오표 적용일. 텍스트는 정오표가 반영된 판이다 |
| `tags` | string[]? | ArkhamDB 검색 태그(`hd` 피해 회복, `hh` 공포 회복 등) |
| `illustrator` | string | 일러스트레이터 |
| `image` | {front, back} | `images/` 상대 경로. 뒷면이 없으면 `back: null` |
| `arkhamdb_url` | string | ArkhamDB 카드 페이지 |

## 텍스트 마크업

| 표기 | 뜻 |
|---|---|
| `[action]` | 행동 격발 기능. 행동 1번을 쓴다 |
| `[reaction]` | 반응 격발 기능. 격발 조건이 생길 때 |
| `[fast]`(영문) / `[free]`(한국어) | 자유 격발 기능. 행동을 쓰지 않는다. 같은 아이콘을 두 언어 데이터가 다르게 적는다(14종). 키워드 신속(Fast)과는 다르다 |
| `[willpower]` `[intellect]` `[combat]` `[agility]` `[wild]` | 의지 / 지식 / 힘 / 민첩 / 만능 |
| `[skull]` `[cultist]` `[tablet]` `[elder_thing]` | 기호 혼돈 토큰. 한국어판에는 이름 없이 아이콘만 인쇄되어 문서에서는 영문 이름을 쓴다 |
| `[auto_fail]` `[elder_sign]` | 자동 실패 / 고대 표식 토큰 |
| `[guardian]` … `[survivor]` | 역할군 아이콘(조사자 덱 구성 문구) |
| `<b>…</b>` | 키워드 라벨(폭로, 강제, 출현, 먹잇감, 목표), 지정 행동(전투. 회피. 조사. 협상. 후퇴.), 결말 지점 `(→R1)` |
| `[[Trait]]` | 특성 이름 참조(카드에는 굵은 기울임으로 인쇄) |
| 줄바꿈 `\n` | 기능 하나가 한 줄 |

기본판 텍스트에는 `[per_investigator]` 태그가 없습니다. 조사자 수 배수는 `health_per_investigator`, `clues_per_investigator` 필드나 "per investigator" 문장으로 나옵니다.

## 효과 구현 범위 가늠

키워드·아이콘이 붙은 카드 수(한 카드가 여러 줄에 들어갈 수 있음)입니다.

| 효과 형태 | 플레이어 | 조우 | 엔진이 제공해야 할 것 |
|---|---|---|---|
| `[action]` 기능 | 24 | 21 | 행동 비용, 조건 검사, 지정 행동이면 기본 행동으로 취급 |
| `[reaction]` 기능 | 14 | 1 | "~한 후"/"~할 때" 격발 시점과 사용 선택 |
| 자유 격발 기능 | 14 | 0 | 플레이어의 행동 기회(창)와 한정 횟수 |
| 신속 카드 | 18 | 0 | 창에서 플레이, "~하려 할 때" 대체 효과 |
| 강제 | 9 | 21 | 조건 감시, 발동 순서 |
| 폭로 | 9 | 17 | 뽑는 즉시 해결, 위협 영역 배치 |
| 사용(이용물) | 10 | 0 | 카드 위 토큰과 소비 |
| 적 키워드(사냥꾼·먹잇감·출현·보복·거대한) | 3 | 29 | 적 이동·출현·교전 규칙 |
| 텍스트 없음 | 3 | 9 | 수치만 쓰면 됨 |

플레이어 카드 103종은 조사자 5, 자산 50, 이벤트 27, 능력 10, 음모 8(약점), 적 3(약점)입니다. 조우 카드 80종은 장소 24, 적 21, 음모 16, 주요사건 8, 주요목적 7, 시나리오 3, 이야기 자산 1(리타 챈들러)입니다.

## 원본(ArkhamDB) 필드 대응

| cards.json | ArkhamDB | 비고 |
|---|---|---|
| `name.ko` / `name.en` | ko API `name` / `real_name` | `subname`, `traits`, `text`, `flavor`, `back_*` 도 같은 방식 |
| `text.en` | en API `text` | ko API 의 `real_text` 와 같다 |
| `type_name.ko`, `faction_name.ko`, `slot_name.ko` | ko 목록 API 의 `type_name`, `faction_name`, `slot` | 단일 카드 API(`/card/<code>`)는 영어로 돌려주므로 목록 API 를 쓴다 |
| `level` | `xp` | |
| `unique` | `is_unique` | |
| `deck` | `encounter_code` 유무 | |
| `quantity.revised_core` | rcore 카드의 `duplicate_of_code` 별 `quantity` 합 | 조우 카드는 `quantity` 그대로 |
| `slots` | `real_slot` | `"Hand x2"` → `["hand","hand"]` |
| `enemy.*` | `enemy_fight`, `health`, `enemy_evade`, `enemy_damage`, `enemy_horror`, `health_per_investigator` | |
| `location.clues_per_investigator` | `clues_fixed` 의 반대 | 기본판에는 `clues_fixed` 가 없다 |
| `investigator.*` | `skill_*`, `health`, `sanity`, `deck_requirements`, `deck_options` | |
| `image` | `imagesrc`, `backimagesrc` | 파일 이름만 따서 `images/` 로 |

뺀 필드: `octgn_id`, `spoiler`, `pack_*`, `url`(한국어 사이트), `exceptional`/`myriad`/`permanent`(기본판은 모두 false), `duplicated_by`/`alternated_by`(재판·대체 카드 코드).

## 제외·예외

| 대상 | 처리 | 이유 |
|---|---|---|
| `01000` 무작위 기본 약점 | 제외 | 덱 빌더의 자리표시자. 실제 카드 아님 |
| `98004` 로랜드 뱅크스 | 제외 | `01001` 과 같은 카드의 재판 |
| ArkhamDB 개정판 목록의 `01683`–`01695`(13종) | 제외 | 다른 확장 카드의 업그레이드 재판. 기본판에 없음 |
| `01121a` / `01121b` | 두 카드로 유지, `linked_to` 로 연결 | 한 장의 앞면이 주요사건 1a '사냥꾼인가 사냥감인가?', 뒷면이 적 '가면 쓴 사냥꾼'. 주요사건이 진행되면 뒤집혀 적으로 등장 |
| 조우 카드 한국어 본문 | `ko: null` | ArkhamDB·arkhamdb-json-data 둘 다 번역 없음(이름·특성은 있음) |
| `01139` 피터 워렌 특성 | 데이터 그대로 | 한국어 데이터에만 '미스캐토닉'이 더 붙어 있다. 영문 기준은 인간형·추종자 |

## 엔진 적재 메모

- 카드 정의(불변) = `cards.json` 항목 하나. 게임 중 카드 인스턴스 = {정의 `code`, 소유자, 조종자, 영역, 소진 여부, 토큰(피해·공포·단서·파멸·자원·이용물), 부착 대상}. 정의와 인스턴스를 나누면 같은 카드 2장, 개정판 매수 차이를 그대로 다룰 수 있습니다.
- 정의 ID 는 `code` 문자열을 그대로 씁니다. `a`/`b` 접미사 카드는 각각 별도 정의이고, 뒤집기는 "같은 인스턴스가 다른 정의로 바뀜"으로 처리합니다. 양면 카드(`double_sided`)는 한 정의 안의 두 면입니다.
- 엔진 키는 영문 코드(`combat`, `arcane`, `free` 등)로 둡니다. 한국어는 "마법"(Arcane 슬롯과 Spell 특성)처럼 한 단어가 두 개념을 가리키는 경우가 있습니다.
